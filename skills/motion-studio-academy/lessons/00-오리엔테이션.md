# 레슨 00 · 오리엔테이션 — 세 스킬은 무엇이고, 무엇이 되나

**이 레슨이 끝나면** motion-studio · motion-plan · motion-3d 가 각각 무엇을 하는지, 그리고 "이런 영상 되나요?"를 스스로 판단할 수 있다.

## 핵심 셋
1. **motion-studio 가 본체다.** 글 · 문서 · 사진 · 영상 · 녹음을 받아 모션 그래픽 영상(mp4 · 9:16 세로 · 16:9 가로)을 만든다. 이것 하나만 있어도 영상이 된다.
2. **나머지 둘은 도우미다.** motion-plan = 뭘 만들지 함께 정하고 기획서를 넘겨준다. motion-3d = 3D 캐릭터 · 무대 · 소품을 짓는다. 둘 다 motion-studio 가 있어야 돈다.
3. **새로 "생성"은 안 한다.** AI 그림 · 영상 생성, 목소리 합성은 하지 않는다. 가진 자료를 움직이고 꾸미고 잇는다.

## 본문

### 어떻게 영상이 만들어지나 (한 문단)
Claude Design 캔버스에 장면 초안(정지 화면)을 그려 사용자가 보고 고친다 → 파이썬 엔진이 그 화면을 그대로 따라 그리면서 움직임 · 전환 · 소리를 붙여 영상 파일로 **굽는다**.
그래서 사용자는 "디자인 툴처럼 화면을 고치고", 움직임은 엔진이 맡는다.

### 세 스킬 나눠 맡기
| 스킬 | 하는 일 | 언제 부르나 |
|---|---|---|
| motion-studio | 시작 카드 → 기획서 → 시안 → 캔버스 → 굽기 → 피드백 | 만들 것과 자료가 정해졌을 때 |
| motion-plan | 사용 안내 · 기획 도우미 · 레시피 · 시리즈 | 뭘 만들지 모를 때 · 되는지 궁금할 때 |
| motion-3d | 3D 캐릭터 · 세계 · 소품 · 받은 3D 파일 | 3D 길을 고를 때(motion-studio 가 알아서 부르기도 한다) |

motion-plan 은 영상 · 시안 · 캔버스를 만들지 않는다 — 기획서까지 만들고 motion-studio 로 넘긴다.

### motion-studio 의 네 겹
1. 모션 그래픽 — 글 · 도형 · 숫자 · 카메라 · 전환 (출발점)
2. 영상 편집 — 찍은 영상을 자르고 · 얹고 · 자막 · 소리 섞기
3. 애니메이션 — 그림을 넘기는 셀 애니메이션 · 입모양 맞춘 진행자 · 대본으로 이야기 한 편
4. 아날로그 손맛 — 물감 번짐 · 마커 · 색연필 · 도장 · 손글씨 · 붓글씨

### 되는지 보는 순서 ★
처음 보는 요청이면 이 순서로 본다.
1. **겹으로 나눈다** — 무엇이 바탕이고 무엇이 위에 올라가나, 무엇이 움직이나
2. **재료를 본다** — 겹마다 자료가 있나, 사용자가 가져올 것 · 그림을 뽑아 올 것은 무엇인가
3. **경계(아래 표)에 걸리나** 본다
4. 판정
   - ✅ **바로 돼요** — 있는 길로 된다
   - 🟡 **돼요, 다만** — 자료 · 손(사진 · 녹음 · 그림 뽑기)이 필요하거나, 없는 움직임이라 시간이 더 든다
   - ⛔ **안 돼요 → 대신** — 경계에 걸린다

> 가능 목록은 한계가 아니라 예시다. 목록에 없다고 안 된다고 하지 않는다.

### 경계 — 진짜 안 되는 것
| 안 되는 것 | 대신 |
|---|---|
| 그림 · 영상을 스킬이 새로 생성 | 스킬이 주는 프롬프트로 사용자가 GPT · 미드저니에서 뽑아 넣는다 |
| 목소리 합성 · 대신 녹음 | 사용자 녹음 · 일레븐랩스 대본을 받아 사용자가 생성 · 나레이션 없이 |
| 영상 속 사람 · 사물을 바꾸거나 새로 그리기 | 자르고 · 넣고 · 위에 얹는다(자막 · 이름 띠 · 효과) |
| 음악 · 효과음을 인터넷에서 받아 오기 | 코드로 작곡(14 장르) · 가져온 곡 깔기 |
| 업로드 · 플랫폼 설정 | 완성 파일을 받는다 (영상 안 로고 · 끝 화면 · 다음 편 예고는 만든다) |
| 웹페이지(HTML) 결과 · 캔버스에서 움직임 미리보기 | 영상(mp4) + 피드백 뷰어 · 빨리 보려면 초안 굽기 |
| 4K 내보내기 | 1080 기준만 |

### 범위 밖 (이 학습 스킬이 가르치지 않는 것)
장면 코드 · 엔진 함수 짜는 법 · 메뉴판 단품 하나하나의 뜻 · 3D 스타일 세부 값 · 스킬 고치기.
→ 메뉴 단품은 모션 메뉴판 페이지에서 예시 영상으로 보고, 코드 세부는 설치된 motion-studio 의 `reference/map.md` 를 Claude 에게 열게 한다.

## 자주 하는 오해
- "어떤 자료든 받아서 영상으로" → 경계(위 표)에 걸리지 않는 한이다.
- "오프닝/엔딩은 안 한다" → 영상 **안의** 로고 · 인사 · 끝 화면 · 다음 편 예고는 만든다. 안 하는 건 업로드 · 플랫폼 설정이다.

## 확인 문제
1. 뭘 만들지 아직 모르겠다면 어느 스킬을 부를까? → 정답: motion-plan
2. "제품 사진 대신 AI 가 새 제품 그림을 그려서 넣어 줘" — ✅ 🟡 ⛔ 중 무엇이고 대신 무엇을 할까? → 정답: ⛔. 스킬이 주는 프롬프트로 사용자가 GPT · 미드저니에서 뽑아 넣는다(가진 사진을 쓰는 것도 방법)
3. motion-3d 만 설치하면 3D 영상을 만들 수 있을까? → 정답: 아니다. motion-studio(0.33.17 이상)가 있어야 돈다
