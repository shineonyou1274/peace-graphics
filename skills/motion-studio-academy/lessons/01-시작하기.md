# 레슨 01 · 시작하기 — 부르는 법과 시작 카드

**이 레슨이 끝나면** 상황에 맞게 스킬을 부르고, 시작 카드에서 무엇을 고르는지 안다.

## 핵심 셋
1. **부르는 말**: `/motion-studio` 또는 "motion-studio 시작". 이름을 안 불러도 "이 글을 움직이는 영상으로" 같은 말이면 motion-studio 가 쓰인다.
2. **시작 카드에서 7가지를 고른다**: 영상 종류 · 내용 · 비율 · 나레이션 · 분위기 · 캐릭터 애니메이션 · 굽기 위치.
3. **"건너뛰기" = 기본값**: 모션 그래픽 · 9:16 · 나레이션 없음 · 시안 보고 정하기 · 캐릭터 애니메이션 안 함 · 클라우드.

## 본문

### 상황별로 부르기
| 내 상황 | 이렇게 |
|---|---|
| 만들 것 · 자료가 있다 | `/motion-studio` 또는 "motion-studio 시작" → 시작 카드 |
| 뭘 만들지 모름 · 되는지 궁금 · 레시피 · 시리즈 | `/motion-plan` 또는 "motion-plan 시작" |
| 3D 만 짓고 싶다 | `/motion-3d` (영상까지면 motion-studio 로 시작하면 3D 단계에서 알아서 부른다) |
| 새 세션에서 이어 하기 | "motion-studio 이어서 · <작업 폴더 이름>" — 기획서의 "0. 지금 단계"부터 |

### 붙여 넣기로 부르기
이런 글을 붙여 넣으면 어느 단계에서든 알맞은 길로 간다.
- `[Motion Menu]` 로 시작하는 장바구니 글 (모션 메뉴판에서 복사 · 레슨 09)
- `[피드백]` 으로 시작하는 목록 (피드백 뷰어에서 복사 · 레슨 07)
- `[3D Tone]` 글 · 레시피 코드(RCP-02 같은) · `*.motion.zip` 묶음 파일

### 시작 카드의 칸
| 칸 | 고르는 것 |
|---|---|
| 영상 종류 | 모션 그래픽 / 역사 · 지식 해설 / 애니메이션(이야기) / 영상 · 사진 쇼츠 / 화면 녹화 편집 / 영상 초안 편집 / 아직 모르겠어요(기획부터 → motion-plan) |
| 내용 | 글을 붙여 넣거나 자료 위치 |
| 비율 | 9:16 세로(쇼츠) / 16:9 가로 |
| 나레이션 | 넣기 / 안 넣기 |
| 분위기 | 시안 보고 정하기 / 차분 · 경쾌 · 강렬 / 참조 이미지 / 직접 적기 |
| 캐릭터 애니메이션 | 사용 안 함 / 리액션 / 리액션 + 이동 |
| 굽기 위치 | 클라우드(기본) / 내 컴퓨터 (레슨 06) |

- 카드와 내 말이 다르면 **내 말이 먼저**다.
- motion-plan 기획서가 이미 있으면 카드 대신 **빈 칸만** 묻는다.

### 쓸 수 있는 환경
Claude 데스크톱 · 코워크처럼 **Artifact(Design) 도구**와 **컴퓨터 폴더 연결**이 되는 곳. 캔버스 도구가 없으면 motion-studio 는 "캔버스 없이는 안 된다"고 알리고 멈춘다(만화 페이지 길만 예외).

## 자주 하는 오해
- "스킬 이름을 꼭 불러야 한다" → 아니다. 영상으로 만들려는 말이면 알아서 쓰인다.

## 확인 문제
1. 시작 카드에서 "건너뛰기"를 누르면 비율과 굽기 위치는? → 정답: 9:16 · 클라우드
2. 어제 하던 영상을 새 대화에서 이어 하려면 뭐라고 말할까? → 정답: "motion-studio 이어서 · <작업 폴더 이름>"
