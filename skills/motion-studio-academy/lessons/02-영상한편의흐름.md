# 레슨 02 · 영상 한 편의 흐름 — 사람이 하는 6가지

**이 레슨이 끝나면** 영상 한 편이 어떤 순서로 만들어지고, 그중 내가 할 일이 무엇인지 안다.

## 핵심 셋
1. 사람이 하는 일은 **고르기 · 고치기 · 확인하기**가 대부분이다. 짜는 일은 스킬이 한다.
2. 꼭 멈추는 곳은 세 군데: **시안 고르기 → 캔버스 "검수 끝" → "굽기 진행할까요?"**
3. 결과물 = **mp4 + `피드백뷰어.html`**. 고치고 싶으면 피드백 뷰어로 짚어서 붙여 넣는다.

## 본문

### 전체 흐름 (스킬 쪽)
```
① 시작 카드 → ② 기획서 정리 → ②-B 표현 기획 · ⏸ 시안 3종 고르기
→ ③ 캔버스 초안 · ⏸ "검수 끝" → ④ 효과 계획 → ⑤ 글꼴 → ⑥ 나레이션(선택)
→ ⑦ 장면 코드 · 점검 · ⏸ "굽기 진행할까요?" → 굽기 → ⑧ 피드백(선택 · 몇 번이든)
```

### 사람이 하는 일만
1. **시작 카드**에서 고른다 (기획서가 있으면 빈 칸만)
2. **시안 3가지** 중 하나를 고른다 — 같은 내용을 세 갈래 정지 화면으로
3. **캔버스**를 보고 직접 고치거나 말로 알리고, 메모를 남긴 뒤 **"검수 끝"**
4. 없는 **글꼴**만 받아 넣는다 · 나레이션이면 **녹음**한다
5. "장면 N개, 약 M초예요. 굽기 진행할까요?"에 **답한다** → mp4 + 피드백 뷰어
6. (원할 때) **피드백 뷰어**로 짚어 붙여 넣으면 고쳐서 다시 굽는다

### 시안은 길마다 다르다
| 길 | 시안 |
|---|---|
| 모션 그래픽 · 앱 화면 목업 | 룩 시안 3종 (정석 1 + MotionStudio Style 2) |
| 사진 쇼츠 | 짜임 시안 3종 (사진 가득 · 스티커 카드 콜라주 · 원테이크 줌) |
| 역사 · 지식 해설 | 스타일 시안 3가지 |
| 찍은 영상에 틀만 얹기 | 데코 시안 3가지 |
| 레시피 | 시안 없음 — 코스가 곧 룩 |

### 시간 감각
- 짧은 쇼츠 한 편 = 대화 **15분 안팎**. 굽기 자체는 내 컴퓨터에서 수십 초.
- 느린 쪽은 굽기가 아니라 **짜는 대화**다.

### 긴 영상
장면이 15개를 넘으면 10장면쯤씩 **장**으로 나눠, 장마다 캔버스 → 검수 → 확인하고, 마지막에 전체를 한 번 굽는다.

## 자주 하는 오해
- "사람이 할 일은 시안 · 검수 · 굽기 확인 셋뿐" → 모션 그래픽 기본 길 기준이다. 길에 따라 그림 뽑기(GPT · 미드저니) · 녹음 · 글꼴 받기 · 컷 표 확인 · 3D 확인 그림 같은 멈춤이 더 있다.
- "레시피는 묻지 않고 끝까지" → 그래도 캔버스 검수와 굽기 명령 두 곳에서는 멈춘다.

## 확인 문제
1. 캔버스를 다 봤다는 신호로 뭐라고 말할까? → 정답: "검수 끝"
2. 사진 쇼츠 길의 시안 3종을 말해 보자. → 정답: 사진 가득 · 스티커 카드 콜라주 · 원테이크 줌
3. 짧은 쇼츠를 만들 때 시간이 가장 많이 드는 건 굽기일까 대화일까? → 정답: 대화(짜는 과정)
