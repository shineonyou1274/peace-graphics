# 레슨 03 · 영상 종류별 길 — 내 자료는 어디로 가나

**이 레슨이 끝나면** 내가 가진 자료를 보고 어느 길로 갈지, 무엇을 준비할지 고를 수 있다.

## 핵심 셋
1. **자료가 길을 정한다** — 글이면 모션 그래픽, 사진 여러 장이면 사진 쇼츠, 긴 녹화면 화면 녹화 편집.
2. 그림 · 녹음이 필요한 길(해설 · 애니메이션)은 **사용자가 뽑고 녹음**한다. 스킬은 프롬프트와 대본을 준다.
3. 원문에 없는 사실 · 숫자는 **넣지 않는다**.

## 본문

### 길 지도
| 내 자료 · 하고 싶은 것 | 길 | 준비 | 꼭 알 것 |
|---|---|---|---|
| 글 · 기획만 있다 | **모션 그래픽(기본)** | 내용 글 | 스킬이 한 줄 요약 · 전할 것 · 원문 사실 · 그림 재료를 먼저 정리 |
| PDF · 브로슈어 · 보고서 | **문서** | 문서 파일 | 쪽 화면을 통째로 넣지 않는다 — 다시 짜고 그림만 꺼낸다 · 브랜드 색 |
| 진행자가 말하며 설명 | **역사 · 지식 해설** | 그림 · 녹음 (없이 먼저 시작도 됨) | 진행자 둘도 된다 · 그림 오기 전엔 코드 그림으로 짓고 나중에 바꿔 단다 |
| 대본 · 캐릭터로 이야기 한 편 | **애니메이션(이야기)** | 대본 · 캐릭터 그림 · 대사 녹음 | 한 편 · 캐릭터 2~3명 · 16:9 기본 · 캐릭터 방식 = GIF 조립 / 벡터 관절 / 3D |
| 사진 여러 장 | **사진 쇼츠** | 사진 · 짧은 정보 | 보통 20~30초 · 장면당 3~4초 · 중복만 빼고 최대한 많이 |
| 폰 영상 | **폰 영상 쇼츠 · 영상 넣기** | 영상 파일 | 자르고 · 예능 자막 · 이름 띠 · 껍데기 · 영상은 내 컴퓨터 굽기 권장 |
| 긴 화면 녹화 | **화면 녹화 편집** | 녹화 파일 | 컷 표 초안을 먼저 확인받는다 · 원본 크기 상관없음 |
| 앱 · 웹 스크린샷 | **앱 · 웹 화면 목업** | 스크린샷 (상태마다 한 장) | 통째로 깔지 않고 닮게 다시 짓는다 · 개인 정보는 바꾼다 |
| 클립 여러 개 | **영상 초안 편집** | 클립 | 시작 카드에서 고르거나 "초안부터"라고 할 때만 |
| 완성된 만화 페이지 | **만화 페이지(β)** | 완성 페이지 | 그림은 고치지 않는다 · 카메라 · 소리 · 빛 한 겹 |
| 3D 캐릭터 · 세계 | **3D** | 3D 렌더 그림체 원화 또는 3D 파일 | motion-studio 가 motion-3d 를 불러 진행 |
| 다 만든 영상 | **위아래 띠 씌우기** | 영상 · 넣을 글 | 글은 받은 것만 |

### 그림이 필요할 때 누가 뽑나
스킬은 그림을 **생성하지 않는다**. 대신 GPT · 미드저니에 넣을 **프롬프트를 준다** → 사용자가 뽑아서 `재료/` 에 넣는다. 사진 쇼츠의 사람 스티커용 누끼 PNG 도 사용자가 만든다(프롬프트를 준다).

### 애니메이션 한계
- 한 편 안에서 회차를 이어 쓰는 길은 없다. 시리즈 폴더에서 편마다 한 편씩은 된다.
- 손그림 캐릭터를 3D 로 바꾸는 건 안 된다.

## 자주 하는 오해
- "PDF 를 넣으면 그 쪽이 그대로 영상에 나온다" → 아니다. 내용을 다시 짜고 안의 그림만 꺼내 쓴다.

## 확인 문제
1. 가게 홍보 글만 있다. 어느 길일까? → 정답: 모션 그래픽(기본)
2. 30분짜리 화면 녹화로 사용법 영상을 만들고 싶다. 스킬이 먼저 확인받는 것은? → 정답: 컷 표 초안
3. 해설 영상을 만들고 싶은데 그림이 아직 없다. 시작할 수 있을까? → 정답: 있다. 코드 그림으로 먼저 짓고, 그림이 오면 바꿔 단다
