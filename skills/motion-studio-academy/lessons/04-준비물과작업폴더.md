# 레슨 04 · 준비물과 작업 폴더

**이 레슨이 끝나면** 자료를 어디에 놓는지, 처음 쓸 때 무엇이 설치되는지, 클라우드 작업의 주의점을 안다.

## 핵심 셋
1. 자료는 **작업 폴더**에 넣고 **이름만** 말하면 스킬이 찾아 읽는다.
2. **컴퓨터 폴더를 연결**해 두면 그 폴더가 작업 폴더가 되고, 이어 하기 · 시리즈가 된다.
3. 연결 없이 클라우드에서 하면 **세션이 끝날 때 중간 파일이 사라진다**(캔버스만 남는다).

## 본문

### 작업 폴더 구조
```
내영상/
├── 재료/    사진 · 영상 · 문서 · 그림
├── style/   참조 이미지 (이 느낌으로)
├── fonts/   글꼴 파일
├── voice/   녹음
├── out/     구운 영상이 나오는 곳
└── 기획서.md  지금 단계와 정한 것 (이어 가기 문서)
```

### 시리즈라면
시리즈 폴더 하나에 편 폴더(`01_` · `02_` …)와 `공유/`(글꼴 · 로고 · 캐릭터 · 편마다 같은 화면 · 소리)를 둔다. 시리즈 뼈대와 편 기획서는 motion-plan 이 만든다.

### 처음 쓸 때 — 점검
처음이면 점검 명령이 빠진 것(ffmpeg · 파이썬 패키지 · 사운드폰트 · 글꼴)을 받는다.
- **클라우드**: 스킬이 알아서 한다.
- **내 컴퓨터 굽기**: 스킬이 명령을 주고 사용자가 돌린다.
- 사운드폰트(약 31MB)를 못 받으면 **배경음 없이** 굽는다(효과음은 합성 소리로 나온다).

### 글꼴
- 제목 글꼴은 **무료 · 상업 이용 가능한 오픈 글꼴**이면 무엇이든 된다.
- Google Fonts 에 없는 글꼴은 사용자가 파일을 준다. 없으면 Pretendard 로.
- 캔버스에 쓴 글꼴과 영상 글꼴이 같아야 줄바꿈이 같다.

### 클라우드 작업의 주의
| | 폴더 연결 O | 폴더 연결 X (클라우드) |
|---|---|---|
| 자료 주는 법 | 폴더에 넣고 이름만 | 대화창 첨부 |
| 세션 끝나면 | 다 남는다 | 기획서 · 녹음 등 중간 파일 사라짐 (캔버스만 남음) |
| 이어 하기 · 시리즈 | 된다 | 어렵다 → 폴더 연결 권장 |

## 자주 하는 오해
- "처음 쓰면 빠진 건 묻지 않고 받는다" → 클라우드일 때 이야기다. 내 컴퓨터 굽기면 명령만 주고 사용자가 돌린다.

## 확인 문제
1. 참조 이미지는 어느 폴더에 넣을까? → 정답: `style/`
2. 클라우드에서 작업하고 세션을 닫았다. 남는 것은? → 정답: 캔버스 (기획서 · 녹음 같은 중간 파일은 사라진다)
3. 배경음이 안 나온다면 무엇을 못 받았을 가능성이 클까? → 정답: 사운드폰트
