# 레슨 06 · 굽기 위치 — 클라우드 vs 내 컴퓨터

**이 레슨이 끝나면** 영상에 맞는 굽기 위치를 고르고, 내 컴퓨터 굽기 명령을 돌릴 수 있다.

## 핵심 셋
1. **굽기** = 장면을 영상 파일(mp4)로 만드는 일.
2. **클라우드(기본)** = 스킬이 굽는다. 짧고 가벼운 영상에. **내 컴퓨터** = 사용자가 터미널에서 명령을 돌린다. 길고 무거운 영상에.
3. 내 컴퓨터를 골라도 **점검 · 정지 화면은 클라우드에서 스킬이** 한다(3D 는 예외).

## 본문

### 비교
| | 클라우드 | 내 컴퓨터 |
|---|---|---|
| 누가 굽나 | 스킬 | 사용자 (명령 붙여 넣기) |
| 맞는 영상 | 짧고 가벼운 영상 · 설치 없이 바로 | 길거나 무거운 영상 · 영상 재료가 크다 · 빨리 받고 싶다 |
| 준비 | 없음 | 컴퓨터 폴더 연결 · 파이썬 3 · ffmpeg (3D 면 playwright + chromium) |
| 속도 예시 | 영상이 든 90초 16:9 = 십수 분 | 같은 영상 = 맥에서 몇 분 |
| 한계 | 영상 첨부 · 결과 보내기에 용량 한도 · 3D 는 몇 배 느림 | 끝나는 순간을 스킬이 못 본다 |

- 고르는 곳: motion-studio **시작 카드**. (motion-plan 은 정하지 않는다)
- 폴더 연결 없이 "내 컴퓨터"를 고르면 클라우드에서 굽고 알려 준다.

### 내 컴퓨터 굽기 — 실제로 하는 일
1. 스킬이 설치본 사본(`_motion-studio/`, 3D 면 `_motion-3d/` 도)을 작업 폴더로 보낸다.
2. 스킬이 명령 두 줄을 준다 — 이런 모양이다:
   ```
   cd "<작업 폴더>"
   python3 scenes.py --bake
   ```
3. 터미널에 붙여 넣고 기다린다. 끝나면 `out/` 에 mp4, 작업 폴더에 `피드백뷰어.html` 이 생긴다.

### 쓸모 있는 굽기 옵션 (스킬이 명령으로 준다)
| 하고 싶은 것 | 옵션 |
|---|---|
| 움직임만 빨리 보기 (절반 시간 · 낮은 화질) | `--draft` |
| 긴 영상 나눠 굽기 | `--part 1/3` → `--part 2/3` → `--part 3/3` → `--join 3` |
| 어디서 느린지 보기 | `--speed` |

### 윈도우에서는?
된다. 다만 스킬의 설치 · 명령 안내는 맥 기준이라, 같은 도구(파이썬 3 · ffmpeg)를 윈도우용으로 설치해 쓴다.

### 굽기 화면에 ⚠ 버전 알림이 뜨면
작업 폴더의 `_motion-studio/` 사본이 설치본보다 옛 버전이다 → 스킬에게 사본을 다시 보내 달라고 한다.

## 자주 하는 오해
- "내 컴퓨터에서 굽기를 고르면 Claude 가 내 컴퓨터에서 굽는다" → 아니다. **사용자가** 터미널에 명령을 붙여 돌린다.
- "4K 로 뽑을 수 있다" → 1080 기준만 된다.

## 확인 문제
1. 영상 클립이 잔뜩 든 2분짜리 16:9 영상. 어디서 구우면 좋을까? → 정답: 내 컴퓨터
2. 움직임만 빨리 확인하고 싶을 때 쓰는 옵션은? → 정답: `--draft`
3. 내 컴퓨터 굽기를 골랐을 때 점검(QA)은 누가 어디서 하나? → 정답: 스킬이 클라우드에서 (3D 는 예외)
