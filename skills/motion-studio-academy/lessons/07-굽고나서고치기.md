# 레슨 07 · 굽고 나서 고치기 — 피드백 뷰어와 배경음 바꾸기

**이 레슨이 끝나면** 피드백 뷰어로 고칠 곳을 짚어 보내고, 다시 굽지 않고 배경음만 바꿀 수 있다.

## 핵심 셋
1. 굽기가 끝나면 작업 폴더에 **`피드백뷰어.html`** 이 생긴다 → 열어서 보며 짚고 → **"목록 복사"** → 대화에 붙여 넣기.
2. 스킬은 바로 고치지 않고 **"제가 이해한 것" 표**를 먼저 보인다 → OK 뒤에만 고친다.
3. **배경음만** 바꿀 때는 영상을 다시 굽지 않는다 (`--rebgm` · 몇 초).

## 본문

### 피드백 뷰어 단축키
| 키 | 하는 일 | 남는 것 |
|---|---|---|
| `N` | 여기 문제 | 시각 하나 + 종류(화면 표시 · 글씨 · 카메라 · 타이밍 · 소리 · 전환 …) + 메모 |
| `I` / `O` | 범위 시작 / 끝 | 범위 + 종류(들어내기 · 빠르게 · 느리게 · 멈춰서 보여 주기 · 꼭 살리기) |
| `[` / `]` | 앞 · 다음 대사로 (자막이 있을 때) | — |
| 목록 복사 | `[피드백]` 으로 시작하는 목록 | — |

- 대충 짚어도 된다. **정확한 자리와 뜻은 스킬이 찾는다.**
- 여러 개는 모아서 한 회차로. 몇 번이든 되풀이할 수 있다.
- 뷰어는 로컬 파일로 연다(영상이 커서 아티팩트로 올리지 않는다). 클라우드 작업이면 영상 · 뷰어를 같이 보내 준다.

### 어디서 고치나
| 고칠 것 | 고치는 곳 |
|---|---|
| 시간 · 무엇 (타이밍 · 길이 · 빼기 · 글귀 · 소리) | 장면 코드 (스킬이) |
| 모양 (위치 · 글꼴 · 크기 · 색) | 캔버스 |
| 화면에 없던 글자 · 그림 얹기 | 작은 보드 하나로 (모양 일) |

### 배경음만 바꾸기 — 다시 굽지 않는다
| 하고 싶은 것 | 명령 |
|---|---|
| 장르 바꾸기 | `python3 scenes.py --rebgm 로파이` |
| 같은 장르 다른 곡 | `python3 scenes.py --rebgm` |
| 마음에 든 곡 다시 | `python3 scenes.py --rebgm --seed <숫자>` |
| 가져온 음악 깔기 | `python3 scenes.py --rebgm 곡.mp3` (크기: `--gain 0.15` 작게 / `0.3` 크게 · 기본 0.22) |
| motion-studio 로 안 만든 mp4 | `python3 <스킬 폴더>/scripts/tools.py rebgm 영상.mp4 --style 로파이` |

- 결과는 `out/<제목>_새배경음.mp4` (원본은 남는다)
- 장르를 바꾸면 **효과음 묶음도 같은 결로** 바뀐다 (다른 묶음은 `--kit`)
- 가져온 곡은 장면 바뀜에 맞춰 곡 조각을 잇고, 곡의 진짜 끝으로 맺는다

## 자주 하는 오해
- "피드백을 붙여 넣으면 바로 고쳐진다" → "제가 이해한 것" 표를 먼저 보고 OK 해야 고친다.
- "배경음을 바꾸려면 처음부터 다시 굽는다" → 아니다, `--rebgm` 으로 소리만.

## 확인 문제
1. 피드백 뷰어에서 "여기 문제"를 찍는 키는? → 정답: `N`
2. 영상 12초~15초를 빼고 싶다. 어떤 키로 범위를 잡을까? → 정답: `I`(시작) / `O`(끝) → 종류 "들어내기"
3. 배경음을 로파이로 바꾸려면? → 정답: `python3 scenes.py --rebgm 로파이`
