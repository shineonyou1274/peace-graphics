# 레슨 08 · 소리 · 나레이션 · 자막

**이 레슨이 끝나면** 배경음 · 효과음이 어떻게 만들어지는지 알고, 나레이션 녹음과 자막 받아쓰기를 할 수 있다.

## 핵심 셋
1. 소리는 파일이 아니라 **코드로 작곡**한다 — 배경음 14 장르 · 효과음 묶음 9개 · 영상마다 새 곡.
2. 나레이션은 **사용자가 녹음**한다. 스킬은 문장 단위 원고와 `03_녹음대본.md` 를 준다.
3. 자막은 **받아쓰기 → 확인표 → 반영** 순서. Claude 는 소리를 못 들어서 받아쓰기는 짐작이다 — 틀린 말만 고친다.

## 본문

### 배경음 · 효과음
- 배경음: 코드로 작곡 · 14 장르 · 같은 장르도 곡이 매번 다르다
- 정한 곡은 `배경음_씨앗.txt` 에 숫자로 남아, 다시 구워도 같은 곡이 나온다 (곡 번호 같은 것)
- 효과음: 묶음 9개(경쾌 팝 · 시네마 · 동화 …) · 한 영상 = 묶음 하나에서 출발
- 가져온 음악 · 효과음 파일도 쓴다

### 나레이션 녹음
1. 시작 카드에서 나레이션 "넣기"
2. 스킬이 원고와 `03_녹음대본.md` 를 준다
3. 녹음한다 — 한 문장씩 · 몇 문장씩 · 한 파일로 쭉, **다 된다** (받아쓰기로 문장대로 자른다)
4. 장면 길이는 대사 길이에 맞춘다

- **원고 없이 이미 녹음해 둔 나레이션**도 된다 — 받아쓰기로 원고를 만든 뒤 자른다.
- **일레븐랩스**: 시작 카드에서 "일레븐랩스 v4 문법"을 함께 고르면 연기 태그를 붙인 `03_녹음대본_일레븐.md` 도 준다 → 일레븐랩스에서 블록째 붙여 생성 → mp3 를 넣는다.
- 받아쓰기가 못 찾은 문장(❌)만 다시 녹음 · ⚠ 줄은 사용자가 들어 확인.

### 소리 크기
- 기본: **목소리가 주인공** (배경음 · 효과음이 목소리의 반쯤)
- 대사가 나오는 동안 배경음은 절반으로 내려간다
- 목소리를 덮으면 점검에서 ⚠ 가 뜬다
- 바꾸고 싶으면 "배경음을 반으로 줄여 줘"처럼 말하면 된다 (이미 구운 영상이면 화면은 두고 소리만 다시)

### 자막 (받아쓰기)
1. 받아쓰기 — 처음 한 번 모델 약 **560MB** 를 받는다
2. ⏸ **확인표** — 틀린 말만 고친다
3. 반영해 자막을 얹어 굽는다 → `<이름>_자막.mp4` (원본 영상은 그대로)

확인 안 한 받아쓰기로 구우면 "자동 자막"으로 표시된다.

### 안 되는 것
- 목소리 합성 · 대신 녹음
- 음악 · 효과음을 인터넷에서 찾아 받아 오기
- 박수 소리는 쓰지 않는다 (빗소리처럼 들린다)

## 자주 하는 오해
- "같은 장르를 고르면 같은 곡이 나온다" → 곡은 매번 다르다. 마음에 든 곡은 씨앗 숫자로 다시 부른다.

## 확인 문제
1. 나레이션을 한 파일로 쭉 녹음해도 될까? → 정답: 된다. 받아쓰기로 문장대로 자른다
2. 지난번 마음에 든 배경음을 다시 쓰려면 무엇이 필요할까? → 정답: `배경음_씨앗.txt` 의 숫자(씨앗)
3. 자막을 굽기 전에 꼭 거치는 단계는? → 정답: 받아쓰기 확인표
