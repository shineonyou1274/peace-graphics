# 레슨 09 · 모션 메뉴판 — 움직임을 코드로 주문하기

**이 레슨이 끝나면** 모션 메뉴판에서 움직임을 골라 코드나 장바구니 글로 주문할 수 있다.

## 핵심 셋
1. **모션 메뉴판** = 움직임 예시 영상과 주문 코드를 모은 페이지 — https://claude.ai/artifact/SionKLsLkEEMqicfABitwV
2. 주문 방법은 셋: **코드 · 이름을 말하기 / 캔버스 노트에 적기 / 장바구니 글 붙여 넣기** (어느 단계에서든).
3. 스킬은 받아 적지 않는다 — **연출을 점검해 적용표로 제안**하고, OK 뒤 적용한다. ("그대로"라고 하면 그대로)

## 본문

### 메뉴판의 네 갈래
| 갈래 | 무엇 | 예 |
|---|---|---|
| 단품 | 그 요소에 그 움직임 | TXT-03 |
| 코스 (STY) | 한 편의 짜임과 룩 | STY-01 |
| 쇼케이스 (SHW) | 종합 견본 — 짜임만 참고 | SHW-… |
| 레시피 (RCP) | 뼈대 + 코스로 끝까지 가는 틀 | RCP-01 ~ 09 → motion-plan 이 받는다 |

### 장바구니 글 모양
메뉴판에서 담고 복사하면 이런 글이 된다. 그대로 대화에 붙여 넣는다.
```
[Motion Menu]
코스 : STY-01
단품 : TXT-01, TXT-04, TXT-02
적용 : 장면 3
순서 : 적용
```
- `적용 :` 줄이 없으면 = 전체 · `순서 :` 줄이 없으면 = 적용(담은 순서대로)
- "장면 N" = 화면 N
- `레시피 :` 줄이 있으면 motion-plan 으로 넘어간다

### 주문하면 생기는 일
1. 표에서 코드를 찾는다
2. 어느 화면 어느 요소에 붙일지 잡는다
3. 연출을 점검한다 — 위계가 뒤집혔나, 센 효과가 연달아 나오나, 한 화면에 등장 방식이 너무 많나 …
4. **적용표**를 한 번 보인다 (제안은 많아야 셋)
5. OK 면 적용

### 메뉴판에 있는데 "없는 메뉴"라고 할 때
설치된 motion-studio 버전에 없는 메뉴다 → 메뉴판 **맨 위에 적힌 버전 이상**으로 새로 설치한다. 스킬은 비슷한 걸 지어내지 않는다.

### 움직임을 말로 찾고 싶을 때
"귀엽게 · 고급스럽게 · 긴박하게"처럼 느낌으로 말해도 된다. 정확히 고르고 싶으면 메뉴판에서 예시 영상을 보고 코드를 가져오는 게 빠르다.

## 자주 하는 오해
- "코드를 주면 그대로 넣는다" → 점검해 제안한다(적용표 → OK). "그대로"라고 하면 그대로.

## 확인 문제
1. 장바구니 글에 `적용 :` 줄이 없으면 어디에 적용될까? → 정답: 전체
2. RCP-02 를 붙여 넣으면 어느 스킬이 받을까? → 정답: motion-plan
3. 메뉴판에 있는 TXT 코드인데 스킬이 "없다"고 한다. 어떻게 할까? → 정답: 메뉴판 맨 위 버전 이상으로 motion-studio 를 새로 설치
