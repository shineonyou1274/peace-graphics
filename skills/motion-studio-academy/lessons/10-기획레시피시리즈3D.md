# 레슨 10 · 기획 · 레시피 · 시리즈 · 3D 맛보기 · 주고받기

**이 레슨이 끝나면** motion-plan · motion-3d 를 언제 쓰는지 알고, 캐릭터 · 소품을 묶음 파일로 주고받을 수 있다.

## 핵심 셋
1. **motion-plan 은 기획까지**만 — 시작 카드의 일곱 문 중 하나를 고르면 `기획서.md` 를 만들어 motion-studio 로 넘긴다.
2. **motion-3d** 는 3D 캐릭터 · 무대까지 3D 인 세계 · 소품 · 받은 3D 파일을 짓는다. motion-studio 0.33.17 이상이 필요하다.
3. **"○○ 내보내줘"** → `<이름>.motion.zip` 하나로 캐릭터 · 소품 · 무대를 주고받는다.

## 본문

### motion-plan 시작 카드 — 일곱 문
| 문 | 이럴 때 |
|---|---|
| 레시피 | 정해진 틀로 묻지 않고 끝까지 가고 싶다 (멈춤은 캔버스 검수 · 굽기 명령 두 곳) |
| 사용법 | 무엇이 · 어디까지 되나 궁금하다 |
| 브레인스토밍 | 아이디어부터 |
| 기획 회의 | 함께 정리하며 정하고 싶다 |
| 바로 기획서 | 생각이 정리돼 있다 |
| 애니메이션 | 이야기 한 편 — 씬 · 컷 표까지 정한다 |
| 시리즈 | 여러 편 — 시리즈 폴더 · 편 기획서 |

- motion-plan 은 굽기 위치를 정하지 않는다 (사용자가 이미 말했으면 기획서에 적어 넘긴다).
- motion-plan 이 그림을 만드는 유일한 예외: 3D 캐릭터 원화 **프롬프트**를 준다.

### motion-3d 가 하는 것 · 안 하는 것
| 한다 | motion-studio 몫 / 안 된다 |
|---|---|
| 3D 캐릭터 · 3D 세계 · 소품 3D · 받은 3D 파일 · 설명서로 짓기 · 3D 스타일 · 3D 싸움 연출 · 효과음 글자 3D | 와이어 · 3D 글자 · 3D 타이틀 · 레이저 각인 같은 모션 그래픽 3D 부품은 motion-studio 몫 · 손그림 캐릭터를 3D 로 ✗ |

- 준비: 3D 렌더 그림체 원화 또는 받은 3D 파일
- 내 컴퓨터 굽기면 3D 확인 그림도 내 컴퓨터에서 (playwright + chromium 필요)
- 클라우드에서 3D 는 몇 배 느리다
- 세부는 원작자의 `motion-studio-3d.4ai.md` · `motion-studio-plan.4ai.md` 문서를 본다

### 주고받기 — 묶음(.motion.zip)
1. 만든 쪽: "○○ 캐릭터 내보내줘" → `<이름>.motion.zip`
2. 받는 쪽: 작업 폴더에 넣거나 첨부하고 "이거 써줘" → 다시 짓지 않고 쓴다
- motion-studio 0.33.2 이상
- 만든 버전이 받는 쪽 설치 버전보다 새것이면 풀지 않고 업데이트를 안내한다
- 녹음 · 구운 칸은 묶음에서 빠진다

## 확인 문제
1. 여러 편짜리 유튜브 시리즈를 계획 중이다. 어디서 시작할까? → 정답: motion-plan 의 "시리즈"
2. 손으로 그린 캐릭터를 3D 로 움직일 수 있을까? → 정답: 안 된다 (3D 렌더 그림체 원화나 3D 파일이 필요)
3. 친구가 만든 캐릭터를 받으려면 어떤 파일이 필요할까? → 정답: `<이름>.motion.zip`
