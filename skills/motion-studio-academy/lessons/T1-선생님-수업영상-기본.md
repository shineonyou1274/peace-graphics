# 선생님 레슨 T1 · 수업 영상 기본 — 무엇을 · 어떻게 · 무엇을 조심하나

**이 레슨이 끝나면** 수업에 쓸 영상을 어떤 모양으로 만들지 정하고, 교실에서 생기는 주의점(정확성 · 저작권 · 학생 정보)을 안다.

## 핵심 셋
1. **한 장면 = 개념 하나.** 수업 영상은 "멋"보다 "한 번에 하나씩 보이기"가 먼저다. 등장 순서가 곧 설명 순서다.
2. **내용의 정답은 선생님이 쥔다.** motion-studio 는 원문에 없는 사실 · 숫자를 넣지 않는다 — 정의 · 수치 · 연도 · 그래프 값은 선생님이 준 글에서만 나온다. 그러니 **보낼 글을 먼저 정확하게** 쓴다.
3. **그림 · 목소리는 선생님이 가져온다.** 스킬은 그림을 생성하지 않고 목소리를 합성하지 않는다. 대신 프롬프트 · 녹음 대본을 준다.

## 본문

### 어떤 모양으로 만들까
| 쓰는 곳 | 비율 | 길이 감각 | 길 |
|---|---|---|---|
| 수업 시작 동기 유발 · 개념 한 줄 | 16:9 (TV · 프로젝터) | 30초~1분 | 모션 그래픽 |
| 개념 설명 (진행자가 말하며) | 16:9 | 1~3분 | 역사 · 지식 해설 (그림 · 녹음 필요 · 없이 먼저 시작도 됨) |
| 학생 복습용 · 학급 채널 쇼츠 | 9:16 | 20~60초 | 모션 그래픽 · 사진 쇼츠 |
| 에듀테크 사용법 안내 (패들렛 · 구글 클래스룸 등) | 16:9 | 1~3분 | 화면 녹화 편집 |
| 행사 · 체험학습 돌아보기 | 9:16 | 20~30초 | 사진 쇼츠 · 폰 영상 쇼츠 |
| 가정통신문 · 안내문 요약 | 9:16 | 20~40초 | 문서 (PDF 를 다시 짜서) |

- 정해진 길이 한도는 없다. 길수록 굽기가 오래 걸린다. 장면이 15개를 넘으면 장으로 나눠 만든다.
- 프로젝터로 틀 때는 글자가 커야 한다. 캔버스에서 핵심 글자를 크게 키워 두자.

### 수업용 원고 쓰는 법 (붙여 넣을 글)
motion-studio 는 글을 받아 **한 줄 요약 · 전할 것 · 원문 사실 · 그림 재료**를 먼저 정리한다. 그러니 원고를 이렇게 주면 좋다.
```
주제: 일차함수의 기울기
대상: 중2 · 수업 도입 1분
전할 것: 기울기 = x가 1 늘 때 y가 얼마나 느나
원문 사실:
- y = 2x + 1 에서 x가 1 늘면 y는 2 는다
- 기울기가 클수록 직선이 가파르다
- 기울기가 음수면 오른쪽 아래로 내려간다
마무리 한 마디: "기울기는 가파름의 숫자다"
```
- **원문 사실**에 쓴 것만 화면에 나온다. 값 · 연도 · 정의는 여기서 확인해 둔다.
- "전할 것"이 둘 이상이면 영상을 나누는 게 낫다.

### 조심할 것
| 무엇 | 왜 · 어떻게 |
|---|---|
| 교과서 · 문제집 그림 · 지문 | 저작권이 있다. 수업 안에서만 쓰더라도 학교 · 교육청 지침을 따른다. 공개(유튜브 등)할 영상이면 직접 만든 그림 · 공개 이용 허락된 자료만 |
| 학생 얼굴 · 이름 · 목소리 | 학생 · 보호자 동의를 받은 것만. 사진 쇼츠는 특히. 앱 화면 목업은 개인 정보를 다른 말로 바꿔 주지만, 사진 · 영상 속 얼굴은 자동으로 가리지 않는다(영상 속 사람을 바꾸지 않는다) |
| 글꼴 | 무료 · 상업 이용 가능한 오픈 글꼴이면 된다. 없으면 Pretendard |
| 음악 | 배경음은 코드로 작곡하니 저작권 걱정이 덜하다. 가져온 음악은 이용 허락을 확인 |
| 사실 정확성 | 스킬은 원문을 지키지만 원문이 틀리면 영상도 틀린다. 굽기 전 확인 2 에서 화면 글자를 한 번 더 본다 |

### 선생님 추천 설정
- 시작 카드: 영상 종류 = 모션 그래픽 · 비율 = 16:9(수업) 또는 9:16(쇼츠) · 분위기 = **차분** (수업은 쿵쿵 센 효과가 집중을 깬다)
- 나레이션: 선생님 목소리 녹음이 학생에게 가장 친근하다. 한 파일로 쭉 녹음해도 문장대로 잘라 준다.
- 굽기 위치: 1분 안팎이면 클라우드, 영상 · 녹화가 들어가면 내 컴퓨터.

## 확인 문제
1. 그래프 값이 원고에 없으면 motion-studio 가 알아서 채워 넣을까? → 정답: 아니다. 원문에 없는 숫자는 넣지 않는다. 선생님이 원고에 값을 적어 준다
2. 수업 도입용 1분 영상에 어울리는 분위기는? → 정답: 차분 (센 효과는 집중을 깬다)
3. 체험학습 사진 쇼츠를 학급 채널에 올리기 전에 확인할 것은? → 정답: 사진에 나온 학생 · 보호자의 동의
