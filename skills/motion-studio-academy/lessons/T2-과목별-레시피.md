# 선생님 레슨 T2 · 과목별 레시피 — 수학 · 과학 · 국어 · 영어 · 사회

**이 레슨이 끝나면** 내 과목 개념을 어떤 움직임으로 보여 줄지 고르고, 모션 메뉴판 코드로 주문할 수 있다.

> 메뉴판 코드는 모션 메뉴판(https://claude.ai/artifact/SionKLsLkEEMqicfABitwV)에서 예시 영상으로 먼저 보고 고른다.
> 판정 기호: ✅ 바로 돼요 · 🟡 돼요, 다만(준비 · 확인이 더 필요) · ⛔ 안 돼요 → 대신
> 가르칠 때: 사용자의 과목 절만 연다. 전 과목을 한꺼번에 보이지 않는다.

## 수학
| 개념 | 판정 | 어떻게 | 코드 |
|---|---|---|---|
| 정의 · 성질 · 공식 한 줄 | ✅ | 글자로. 핵심 낱말은 짚기 | TXT-02 · SHP-02 |
| 도형 변환 (삼각형 → 사각형, 원 · 다각형) | ✅ | 한 도형이 다른 모양으로 변신 | SHP-05 도형 모핑 |
| 자료의 정리 (막대 · 원 · 꺾은선) | ✅ | 값은 원고에 적은 것만 | DAT-02 · DAT-03 · DAT-10 |
| 비율 · 백분율 (100명 중 37명) | ✅ | 사람 아이콘 100개가 하나씩 켜짐 | DAT-07 |
| 수 세기 · 큰 수 | ✅ | 숫자 오르기 · 슬롯 카운터 | DAT-01 · DAT-05 |
| 좌표평면 · 함수 그래프 (y = 2x + 1, y = x²) | 🟡 | 캔버스에 **선 그림(SVG)** 으로 좌표축과 곡선을 그리면 선이 그어지며 나타난다(SHP-01). 그래프 위 점 · 값은 원고에 적고, 캔버스에서 눈으로 맞는지 꼭 확인 | SHP-01 · SHP-02 |
| 간단한 식 (2x + 3 = 7) | ✅ | 글자로 쓴다 | TXT-02 · TXT-04 |
| 분수 · 근호 · 적분 같은 2층 수식 | 🟡 | 글자 한 줄로는 어렵다 → 수식을 그림(SVG · PNG)으로 만들어 `재료/` 에 넣으면 그림처럼 등장 · 확대. ² ³ √ π 같은 기호는 글꼴에 없으면 □ 로 깨지니 캔버스 · 점검에서 확인 | PIC-09 · SHP-02 |
| 풀이 과정 한 줄씩 | ✅ | 줄마다 차례로, 바뀐 부분은 짚기 | TXT-04 · SHP-02 · UI-15 |

**수학 팁** — 식을 바꾸는 장면은 "앞 줄 그대로 + 바뀐 부분만 색"이 이해가 빠르다. 캔버스에서 바뀐 글자 색을 직접 바꾸면 된다.

## 과학
| 개념 | 판정 | 어떻게 | 코드 |
|---|---|---|---|
| 천체의 운동 (공전 · 위성) | ✅ | 가운데를 타원 궤도로 돈다 · 뒤로 가면 가려지고 작아짐 | SHP-09 궤도 돌기 |
| 기계 · 힘의 전달 (톱니바퀴) | ✅ | 큰 톱니가 돌면 작은 톱니가 반대로 빨리 | SHP-08 |
| 진자 · 흔들림 | ✅ | 한 점을 축으로 흔들리다 잦아듦 | SHP-06 매달려 흔들리기 |
| 물질 · 에너지의 흐름 | ✅ | 굵은 띠가 갈래로 나뉨 (굵기 = 양) — 값은 원고에서 | DAT-08 흐름 갈래 |
| 실험 결과 (온도 변화 · 측정값) | ✅ | 꺾은선 · 막대 · 계기판 · 물 차오르기 — 측정값은 원고에서 | DAT-10 · DAT-02 · DAT-11 · DAT-12 |
| 실험 과정 순서 | ✅ | 단계 진행 + 실험 사진 | UI-15 · PIC-02 |
| 실험 영상 설명 | ✅ | 찍은 영상을 자르고 · 멈추고 짚기 · 자막 | PIC-03 멈추고 짚기 · 폰 영상 길 |
| 낮 · 밤 / 시간 변화 | ✅ | 사진 한 장이 낮에서 밤으로 | PIC-06 |
| 파동 · 물결 | ✅ | 한 점에서 동심원 물결 | FX-08 |
| 세포 · 기관 구조도 | 🟡 | 구조 그림은 선생님이 준비(직접 그림 · 이용 허락된 그림 · GPT 로 뽑기 — 프롬프트를 준다). 받은 그림 위에 짚기 · 돋보기 · 이름표 | PIC-09 · SHP-02 |
| 분자 · 원자 3D 모형 | 🟡 | 3D 는 motion-3d 길 (motion-studio 0.33.17 이상). 3D 렌더 그림체 원화나 3D 파일이 필요 | 레슨 10 |

**과학 팁** — 실험 영상은 굽기가 무거우니 **내 컴퓨터 굽기**를 권한다. "멈추고 짚기"로 관찰 포인트에서 화면을 세우면 학생이 놓치지 않는다.

## 국어
| 개념 | 판정 | 어떻게 | 코드 |
|---|---|---|---|
| 한글 짜임 (자음 · 모음 · 받침) | ✅ | 자모 조각이 날아와 글자로 맞물림 · 초성 · 중성 · 종성 색을 따로 | TXT-06 한글 자모 조립 |
| 글씨 쓰기 · 획순 느낌 | ✅ | 글자가 획 순서대로 써짐 (손글씨 · 붓글씨 결) | TXT-02 |
| 맞춤법 (틀린 말 → 바른 말) | ✅ | 자판처럼 치다 고쳐 침 · 아니지~ 다시 | TXT-09 · CAM-05 |
| 시 낭송 · 작품 읽기 | ✅ | 선생님 녹음 + 줄마다 등장 · 받아쓰기 자막 | TXT-04 · 레슨 08 |
| 문학 작품 줄거리 · 인물 관계 | ✅ | 카드 차례로 · 화살표 짚기 | CAM-03 · SHP-02 |
| 문법 비교 (능동 vs 피동) | ✅ | 나란히 비교 | CAM-04 |
| 이야기 한 편 애니메이션 | 🟡 | 대본 · 캐릭터 그림 · 대사 녹음이 필요. 기획은 motion-plan 애니메이션 | 레슨 03 · 10 |

**국어 팁** — 작품 지문은 저작권이 있는 경우가 많다. 공개 영상이면 저작권이 끝난 작품 · 직접 쓴 예문으로.

## 영어
| 개념 | 판정 | 어떻게 | 코드 |
|---|---|---|---|
| 단어 · 표현 소개 | ✅ | 타자 치기 · 단어가 박자마다 바뀜 | TXT-01 · SEQ-02 |
| 문장 구조 (주어 · 동사 · 목적어) | ✅ | 단어 차례로 · 성분마다 색 · 짚기 | TXT-04 · SHP-02 |
| 틀린 문장 → 바른 문장 | ✅ | 아니지~ 다시 | CAM-05 |
| 듣기 · 따라 말하기 | ✅ | 선생님(또는 원어민 협력 교사) 녹음 + 받아쓰기 자막 · 대사마다 등장 | 레슨 08 |
| 원어민 발음 목소리 만들기 | ⛔ → 대신 | 목소리 합성은 안 한다 → 직접 녹음 · 일레븐랩스 대본을 받아 선생님이 생성해 mp3 로 넣기 | 레슨 08 |
| 대화문 (두 인물) | ✅ | 진행자 둘 해설 · 입모양 맞춘 캐릭터 — 그림 · 녹음 필요 | 해설 길 |
| 단어 퀴즈 | ✅ | 해독 글자로 정답 공개 | TXT-05 |

**영어 팁** — 영어 글꼴은 대부분 된다. 한글이 섞이면 한글이 있는 글꼴(Pretendard 등)을 쓴다 — 한글 없는 글꼴이면 한글이 다른 글꼴로 대신 그려진다.

## 확인 문제
1. 수학 시간, 삼각형이 사각형으로 변하는 장면에 맞는 코드는? → 정답: SHP-05 도형 모핑
2. 과학 시간, 지구가 태양 둘레를 도는 장면은? → 정답: SHP-09 궤도 돌기
3. 국어 시간, 자음 · 모음 · 받침이 모여 글자가 되는 장면은? → 정답: TXT-06 한글 자모 조립
4. 영어 원어민 목소리를 스킬이 만들어 줄까? → 정답: 아니다(⛔). 직접 녹음하거나 일레븐랩스로 선생님이 생성해 넣는다
5. 사회 시간, 조선 시대 사건을 연도순으로 보여 주는 코드는? → 정답: DAT-04 타임라인
6. 분수가 들어간 2층 수식은 어떻게 넣을까? → 정답: 🟡 수식을 그림(SVG · PNG)으로 만들어 `재료/` 에 넣는다
