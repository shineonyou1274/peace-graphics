# 실습 미션

> 영상은 motion-studio 에서 만든다. 이 파일은 무엇을 고르고, 무엇을 확인하면 성공인지 알려 주는 안내서다.

## 미션 1 · 글 한 단락 → 9:16 쇼츠 (입문 · 약 20분)
- **준비물**: 소개하고 싶은 글 3~5문장 (가게 · 동아리 · 책 소개 등)
- **할 일**
  1. `/motion-studio` → 시작 카드: 영상 종류 = 모션 그래픽 · 비율 = 9:16 · 나레이션 = 안 넣기 · 굽기 위치 = 클라우드
  2. 내용 칸에 글을 붙여 넣는다
  3. 룩 시안 3종 중 하나를 고른다
  4. 캔버스에서 화면 하나 이상을 직접 고친다(글자 · 색) → "검수 끝"
  5. "굽기 진행할까요?" → 진행
- **성공 기준**: mp4 를 받았다 · 고친 글자 · 색이 영상 끝 모습에 그대로 나온다
- **배운 것 연결**: 레슨 01 · 02 · 05

## 미션 2 · 피드백 한 바퀴 (입문 · 약 10분)
- **준비물**: 미션 1 의 영상과 `피드백뷰어.html`
- **할 일**
  1. 피드백 뷰어를 연다
  2. `N` 으로 "여기 문제" 하나, `I`/`O` 로 범위 하나(예: 느리게)를 남긴다
  3. "목록 복사" → motion-studio 대화에 붙여 넣는다
  4. "제가 이해한 것" 표를 읽고 OK
- **성공 기준**: 다시 구운 영상에 두 가지가 반영됐다
- **배운 것 연결**: 레슨 07

## 미션 3 · 배경음만 바꾸기 (입문 · 약 5분)
- **준비물**: 구운 영상이 있는 작업 폴더
- **할 일**: "배경음을 로파이로 바꿔 줘" (내 컴퓨터면 `python3 scenes.py --rebgm 로파이`)
- **성공 기준**: `out/<제목>_새배경음.mp4` 가 생겼다 · 화면은 그대로 · 효과음 결도 바뀌었다
- **배운 것 연결**: 레슨 07 · 08

## 미션 4 · 사진 10장 → 사진 쇼츠 (중급 · 약 25분)
- **준비물**: 한 자리(여행 · 행사 · 모임)의 사진 10장 이상 · 무슨 자리 · 언제 · 어디 한 줄
- **할 일**
  1. 컴퓨터 폴더를 연결하고 사진을 `재료/` 에 넣는다
  2. `/motion-studio` → 영상 · 사진 쇼츠 · 9:16
  3. 짜임 시안 3종(사진 가득 · 스티커 카드 콜라주 · 원테이크 줌) 중 하나를 고른다
  4. 검수 끝 → 굽기
- **성공 기준**: 중복 사진만 빠지고 대부분이 들어갔다 · 20~30초 안팎
- **배운 것 연결**: 레슨 03 · 04

## 미션 5 · 메뉴판 주문 (중급 · 약 15분)
- **준비물**: 미션 1 또는 4 의 작업
- **할 일**
  1. 모션 메뉴판 https://claude.ai/artifact/SionKLsLkEEMqicfABitwV 에서 단품 두 개를 장바구니에 담는다
  2. `적용 : 장면 2` 로 복사해 motion-studio 대화에 붙여 넣는다
  3. 적용표를 읽고 하나는 제안대로, 하나는 "그대로"로 답해 본다
- **성공 기준**: 화면 2에 두 움직임이 들어갔다 · 적용표가 무엇을 바꿨는지 설명할 수 있다
- **배운 것 연결**: 레슨 09

## 미션 6 · 내 컴퓨터에서 굽기 (중급 · 약 20분)
- **준비물**: 컴퓨터 폴더 연결 · 파이썬 3 · 터미널
- **할 일**
  1. 시작 카드에서 굽기 위치 = 내 컴퓨터
  2. 스킬이 주는 점검 명령을 한 번 돌린다(처음이면)
  3. "굽기 진행할까요?" 뒤에 받은 명령 두 줄을 터미널에 붙여 넣는다
  4. 먼저 `--draft` 로 움직임만 보고, 괜찮으면 본 굽기
- **성공 기준**: `out/` 에 mp4 · 작업 폴더에 `피드백뷰어.html`
- **배운 것 연결**: 레슨 06
