# 막힐 때 · 설치

## 설치
- **쓸 수 있는 환경**: Claude 데스크톱 · 코워크 — Artifact(Design) 도구와 컴퓨터 폴더 연결이 되는 곳.
- **설치 순서**: motion-studio(필수) → 필요하면 motion-plan · motion-3d. 3D 를 고르면 motion-3d 가 없을 때 설치 안내가 나온다.
- **내 버전 확인**: 각 스킬 폴더의 `SKILL.md` 맨 위 `metadata` → `version`.
- **설치본 찾는 곳** (여기 있는 `motion-studio/` · `motion-plan/` · `motion-3d/` 폴더 · 여럿이면 version 이 가장 새 것):
  1. 다른 스킬 폴더 옆
  2. `/mnt/skills/user` · `private` · `organization` · `plugins` 아래
  3. `~/.claude/skills/`
  4. `~/.claude/skills/synced/*/`
  5. 내 컴퓨터 굽기 작업 폴더면 `_motion-studio/` · `_motion-3d/`
- **내 컴퓨터 굽기 준비**: 파이썬 3 · ffmpeg (3D 면 playwright + chromium) · 윈도우도 되지만 안내는 맥 기준.

## 자주 막히는 곳
| 증상 | 원인 | 해결 |
|---|---|---|
| 캔버스가 안 생긴다 | Artifact(Design) 도구가 없는 환경 · 또는 하루 약 200번 올리기 제한 | 그 도구가 되는 환경에서 · 다음 날 |
| 한글 · 기호가 □ 로 깨진다 | 글꼴에 없는 글자(① ② ♪ ▶ · 제목 글꼴의 `·` `→`) · 캔버스 글꼴을 별명으로 걸었다 | 기호는 글자 · 도형으로 · 글꼴은 실제 이름으로 · `check.py --fix --fonts "글꼴 이름"` |
| 캔버스와 영상의 자리가 다르다 | "검수 끝" 전에 넘어감 · 쌓기 배치(flex · grid) · 다른 글꼴로 봄 · 움직이는 도중을 봄 · 2배 크기 캔버스 | "검수 끝"으로 다시 읽게 하거나 피드백 뷰어로 짚기 |
| 배경음이 없다 | 사운드폰트(약 31MB)를 못 받음 | `check.py <작업 폴더> --fix` |
| 굽기가 "Illegal instruction"으로 죽는다 | pedalboard 최신판 | `pip install "pedalboard==0.9.16"` |
| tinysoundfont 설치가 멈춘다 | pyaudio 빌드 오류 | `pip install tinysoundfont --no-deps` |
| "cannot identify image file"로 멈춘다 | 옛 영상 캐시 | 작업 폴더 `_cache/video` 를 지우고 다시 |
| 굽기 중 디스크 · 시간 부족 | 긴 영상 | 조각 굽기 `--part K/N` → `--join N` · 느린 곳 = `python3 scenes.py --speed` |
| 굽기 화면에 ⚠ 버전 알림 | `_motion-studio/` 사본이 옛 버전 | 스킬에게 사본을 다시 보내 달라고 한다 |
| 점검 뒤 굽기로 안 넘어간다 | 고칠 것이 남아 점검이 굽기를 막음 | 점검 보고대로 고치거나 이유를 남겨 받아들인다 |
| 메뉴판 코드인데 없다고 한다 | 설치된 motion-studio 에 없는 메뉴 | 메뉴판 맨 위 버전 이상으로 새로 설치 |
| motion-plan · motion-3d 가 멈춘다 | motion-studio 가 없거나 버전이 낮다 | 설치 · 업데이트 (`버전표.md`) |
| 녹음 문장이 안 맞는다 | 받아쓰기가 못 찾은 문장 | ❌ 문장만 다시 녹음 · ⚠ 줄은 들어 보고 확인 |
| 시리즈 · 이어 가기가 안 된다 | 폴더 연결 없는 클라우드 작업 | 컴퓨터 폴더 연결 |
| 위에 없는 오류 | — | 원작 스킬 만든 사람(조남경)에게 문의 |
