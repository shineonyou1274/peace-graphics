# 수업 영상 원고 틀 — 복사해서 채우기

motion-studio 시작 카드의 **내용** 칸에 붙여 넣는다. 빈 줄은 지워도 된다.

```
주제:
대상: (학년 · 과목 · 어디에 쓰나 — 수업 도입 / 복습 쇼츠 / 학급 채널)
전할 것: (한 문장 — 둘 이상이면 영상을 나눈다)
원문 사실:
- (화면에 나올 정의 · 값 · 연도 · 예문 — 여기 적은 것만 나온다)
-
-
마무리 한 마디:
출처: (통계 · 연도가 있으면)
요청: (원하는 움직임 · 메뉴판 코드 · 색 · 글꼴 — 없으면 비움)
```

## 잘 쓴 예 vs 아쉬운 예
| 아쉬운 예 | 잘 쓴 예 | 이유 |
|---|---|---|
| "광합성 영상 만들어 줘" | 원문 사실 3줄 + 전할 것 1줄 | 사실이 없으면 화면에 쓸 게 없다(지어내지 않는다) |
| 전할 것: 광합성, 호흡, 증산 작용 | 전할 것: 광합성은 빛으로 양분을 만든다 | 영상 하나 = 전할 것 하나 |
| "그래프 넣어 줘" | "2020~2024 기온: 14.1, 14.3, …(출처)" | 그래프 값은 원고에서만 |
| "원어민 목소리로" | "나레이션 넣기 + 일레븐랩스 대본도" | 목소리 합성은 안 한다 |
