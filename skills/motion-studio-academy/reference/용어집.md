# 용어집

> "사람에게 씀 = 아니오"인 말은 사용자에게 쓰지 않는다. 괄호 안 말로 바꾼다.

| 용어 | 뜻 | 사람에게 씀 |
|---|---|---|
| 굽기 | 장면을 영상 파일(mp4)로 만드는 일 ("렌더" 대신) | 예 |
| 굽기 위치 | 클라우드(스킬이 굽는다) / 내 컴퓨터(사용자가 명령을 돌린다) | 예 |
| 캔버스 | Claude Design 에 그린 장면 초안 묶음 · 영상 하나 = 캔버스 하나 | 예 |
| 아트보드 | 캔버스의 한 장 | 아니오 (→ "화면 N") |
| 화면 N | 캔버스 한 장을 부르는 이름 | 예 |
| 시안 3종 | 같은 내용을 세 갈래로 보인 정지 화면 | 예 |
| 검수 끝 | 캔버스 확인이 끝났다는 사용자 신호 | 예 |
| 기획서 | 작업 폴더의 `기획서.md` — 정한 것과 지금 단계 · 이어 가기 문서 | 예 |
| 작업 폴더 | 영상 한 편의 폴더 (`재료/` · `fonts/` · `voice/` · `out/` …) | 예 |
| 장면 코드 | 작업 폴더의 `scenes.py` — 움직임 · 소리를 적은 파일 | 아니오 |
| 점검 | 굽기 전 한 번 하는 확인 · 점검 모음 그림과 보고 ("QA" 대신) | 예 |
| 정지 화면 | 특정 초의 한 장 ("스틸" 대신) | 예 |
| 피드백 뷰어 | 굽기 끝에 생기는 `피드백뷰어.html` | 예 |
| 모션 메뉴판 | 움직임 예시 영상과 주문 코드를 모은 페이지 | 예 |
| 단품 · 코스 · 쇼케이스 · 레시피 | 메뉴판 갈래 (요소 하나 · 한 편의 짜임과 룩 · 견본 · 뼈대 + 코스) | 예 |
| 장바구니 글 | 메뉴판에서 복사한 `[Motion Menu]` 로 시작하는 글 | 예 |
| 적용표 | 메뉴 주문을 어디에 어떻게 넣을지 스킬이 보이는 제안 | 예 |
| 효과음 묶음 | 결이 맞는 효과음 한 벌 (경쾌 팝 · 시네마 · 동화 …) | 예 |
| 키트 | 영상 한 편의 움직임 · 전환 출발 세트 | 아니오 |
| 배경음 씨앗 | 코드 작곡 곡을 정하는 숫자 · `배경음_씨앗.txt` (곡 번호처럼) | 예 |
| 설치본 사본 | 내 컴퓨터 굽기 때 작업 폴더에 보내는 `_motion-studio/` · `_motion-3d/` | 예 (폴더 이름만) |
| 받아쓰기 확인표 | 받아쓰기 결과를 사용자가 고치는 표 | 예 |
| 캐릭터 방식 | GIF 조립 · 벡터 관절 · 3D | 예 |
| 묶음 (.motion.zip) | 캐릭터 · 소품 · 무대를 주고받는 파일 하나 | 예 |
| 버전 | 스킬의 판 번호 (사람에게는 "판" 대신 "버전") | 예 |
