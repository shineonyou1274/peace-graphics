**사람이 할 일** — 시작 카드 → 시안 3종 고르기 → 캔버스 고치고 "검수 끝" → 글꼴 · 녹음 → "굽기 진행할까요?" → (원하면) 피드백 뷰어.

**길** — 모션 그래픽(기본) · 문서 · 해설 · 애니메이션 · 사진 쇼츠 · 폰 영상 · 화면 녹화 · 앱 목업 · 영상 초안 · 만화 페이지(β) · 3D · 위아래 띠.

**작업 폴더** — `재료/` · `style/` · `fonts/` · `voice/` · `out/` · `기획서.md`. 폴더 연결 없으면 세션 끝에 중간 파일이 사라진다.

**캔버스** — 화면 N = 장면 끝 모습. 자리 · 크기 · 글자 · 색이 그대로. 노트 A/B/C · ✔. 9:16 안전 영역 위 300 · 아래 480 · 오른쪽 200 · 왼쪽 60.

**굽기** — 클라우드(기본 · 스킬이) / 내 컴퓨터(사용자가 `cd` + `python3 scenes.py --bake`). `--draft` 빨리 보기 · `--part K/N` + `--join N` 조각 굽기 · `--speed`.

**고치기** — 피드백 뷰어 `N` · `I`/`O` · 목록 복사 → "제가 이해한 것" 표 → OK. 시간 · 무엇 = 코드 / 모양 = 캔버스.

**소리** — 코드 작곡 14 장르 · 효과음 묶음 9 · 씨앗 숫자로 같은 곡 · `--rebgm` 으로 소리만 다시 · 가져온 곡 `--rebgm 곡.mp3`.
