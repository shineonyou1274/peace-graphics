# peace-class — 수업 모션 그래픽

> **선생님이 원고를 쓰면, 영상은 점 하나가 끌고 간다.** 화면의 사실 · 값은 원고에서만 나오고, 움직임 · 소리 · 틀은 스킬이 맡는다.

Shiny Peace Studio 의 영상 엔진(videointro · videointro2: HTML 장면 → Playwright 로 프레임 → ffmpeg, 코드 작곡 — 악기 설계를 웹 오디오로 옮김)과
영상 스튜디오의 공정 원칙(단계마다 확인 · 싼 시안 먼저 · 추측하지 않기)을 수업 영상에 맞춘 스킬이다.

## 0. 먼저 읽을 것
- `references/수업-취향.md` — 화면 · 소리 · 공정 원칙 (매번)
- `references/장면틀.md` — lesson.json 쓰는 법 · 장면 틀 10가지 · 수업 영상 공식
- `examples/` — `math-slope`(16:9 · 수식 · 그래프 · 흔한 실수) · `history-joseon`(9:16 · 연표 · 비교 · 과정) · `math-data`(9:16 · 막대그래프)

## 1. 원고 받기 → 장면 표 ⏸
선생님에게 받을 것: **주제 · 대상(학년 · 어디에 쓰나) · 전할 것 한 문장 · 원문 사실(정의 · 값 · 연도 · 예문) · 마무리 한 마디**.
빠진 것만 한 번에 묻는다(AskUserQuestion · 넷까지). 원고 틀 = motion-studio-academy `reference/수업-원고-틀.md`.

- **원문 사실에 없는 사실 · 숫자 · 연도는 넣지 않는다.** 교과 내용을 대신 지어 쓰지 않는다 — 모르면 묻는다.
- 함수 식 · 그래프 값처럼 원고에서 계산되는 것(기울기 삼각형의 +1 · +2)은 된다. 계산 결과를 장면 표에 적어 확인받는다.
- 비율: 수업(프로젝터) = 16:9 · 학생 복습 · 학급 채널 쇼츠 = 9:16. 분위기: 대부분 calm, 저학년 · 놀이 = bright, 무거운 주제 = serious.

장면 표를 짜서 보인다(장면마다: 틀 · 화면에 나올 글 · 점이 하는 일 · 대략 초). 공식은 `장면틀.md` "짜는 법". **"좋아요" 전에는 다음으로 가지 않는다.**

## 2. 스튜디오 파일을 만들어 드린다 ⏸ — 스타일 · 시나리오는 선생님이 눈으로 보고 고른다
```bash
SK=<이 스킬 폴더>
python3 $SK/scripts/peace.py new    <작업 폴더> --from science-photosynthesis   # 가장 가까운 예시로 시작
#   → <작업 폴더>/lesson.json 을 장면 표대로 고친다 (형식 = references/장면틀.md)
python3 $SK/scripts/peace.py studio <작업 폴더>                                # → <제목>_스튜디오.html (파일 하나 · 약 4MB)
```
**스튜디오 파일이 이 스킬의 중심이다.** 선생님이 내려받아 브라우저로 열면(인터넷 · 설치 없음):
1. **스타일 고르기** — 지금 장면이 스타일 6가지(형광 · 종이 · 칠판 · 공책 · 모눈 · 청사진)로 나란히 보인다. 눌러서 고른다.
2. **시나리오 고치기** — 장면마다 화면에 나올 글이 칸으로 있다. 고치면 바로 미리보기에 나온다. 장면 더하기 · 지우기 · 순서 바꾸기 · 복제.
3. **목소리** — 장면마다 🎙 녹음(마이크) 또는 파일. 말 길이만큼 장면이 늘고, 말하는 동안 배경음이 낮아진다.
4. **미리보기 · 점검** — 소리와 함께 재생, 넘침 · 겹침을 저절로 점검해 알려 준다.
5. **수업용 파일 저장** — 재생기 파일 하나(`<제목>_수업용.html`)로 저장. 이것을 수업에 쓰고 다른 선생님께 보낸다.
6. **시나리오 저장** — `.json` 으로 저장해 두면 나중에 "시나리오 열기"로 이어서 고치거나, Claude 에게 보내 손보게 할 수 있다.

선생님에게 보낼 것: 스튜디오 파일(`SendUserFile` · display: attach) + 한 줄 안내("내려받아 크롬 · 엣지 · 웨일로 열어 주세요. 1 스타일 → 2 글 고치기 → 수업용 파일 저장") + **화면 글자를 교과서와 대조해 달라는 부탁**.
선생님이 시나리오 json 을 다시 보내면 그것을 lesson.json 으로 두고 이어서 작업한다(스타일 · 녹음도 그 안에 있다).

Claude 가 직접 확인할 때(Node + Playwright 가 있는 환경): `peace.py build` → `peace.py check` 로 정지 화면 시트 · 화면 글자 · 점검을 먼저 본다 — 글 겹침 · 잘림 · 빈 화면을 고친 뒤 스튜디오를 보낸다.

## 3. 다른 결과물
```bash
python3 $SK/scripts/peace.py share <작업 폴더>          # 수업용 파일 하나를 바로 (스튜디오를 거치지 않을 때 · 글꼴을 쓴 글자만 담아 1~2MB)
python3 $SK/scripts/peace.py video <작업 폴더> [--draft] # mp4 (Node + Playwright + ffmpeg 가 있을 때 · build · check 다음에)
python3 $SK/scripts/peace.py blank 수업영상스튜디오.html  # 예시만 담은 빈 스튜디오 (선생님이 Claude 없이 처음부터)
```
- 수업용 파일 조작: 클릭 · 스페이스 = 재생/멈춤 · → ← = 다음/앞 장면 · F = 전체 화면 · R = 처음부터. 멈춰 있으면 제목 화면이 표지.
- mp4 가 안 되는 환경이면 "수업용 파일을 쓰시거나 화면 녹화로 mp4 를 만들 수 있어요"라고 알린다. 설치를 우기지 않는다.

## 4. 목소리
선생님 목소리가 가장 좋다. 장면마다 녹음 대본(한두 문장)을 드리고, 스튜디오의 🎙 녹음으로 바로 녹음하게 한다. 파일로 받으면 `voice/01.wav …` 로 두고 장면에 `"voice": "voice/01.wav"` — studio · share 가 파일 안에 담는다. AI 음성은 선생님이 원하고 크레딧 사용을 승인할 때만(연결된 음성 도구로 만들어 파일로 넣는다).

## 하지 않는 것
- 원고에 없는 사실 · 숫자 · 연도를 지어 넣기 · 교과서 그림 · 지문을 무단으로 넣기
- 그림 · 영상 생성 · 목소리 합성 · 게시(완성 파일까지)
- 학생 얼굴 · 이름이 나오는 자료는 동의를 확인하기 전에 쓰지 않는다

## 새 장면 틀 만들기 (스킬을 키울 때)
`engine/runtime.js` 의 `T.<이름> = (sc, root) => ({ dur, hits, measure(), update(lt), dotAt(lt) })`.
- `update(lt)` 는 같은 lt 에 언제나 같은 화면(렌더러가 프레임마다 seek). 시간에 따른 값만 쓴다(Math.random 은 짓는 때만).
- `measure()` 에서 `dotIn` · `dotOut`(점이 들어오고 나가는 자리)을 잰다. 점이 그 장면에서 무엇인지 먼저 정한다.
- 글 덩어리에 `qa` 클래스를 달면 점검이 넘침 · 겹침을 본다. 화면 글자는 `TEXTS` 에 넣는다. 소리 자리는 `hits` 에 [초, 종류].
- 예시 json 하나와 `장면틀.md` 표 한 줄을 함께 더한다.

## 함정
- 한글 글꼴은 쓴 글자만 담은 조각이다 — 글을 바꾸면 `build` 를 다시(빠진 글자는 시스템 글꼴로 바뀐다). 글꼴: Pretendard(본문 · 제목) · Nanum Pen Script(손글씨) · Anton(숫자 · 라벨) — 모두 OFL.
- 스타일 6가지(`style`): dark 형광 · light 종이 · board 칠판 · note 공책 · grid 모눈 · night 청사진. 선생님이 스튜디오에서 눈으로 보고 고른다 — Claude 가 정하지 않는다(물으면 추천만).
- 수식 안 한글은 `\text{…}` 안에. JSON 에서는 역슬래시를 두 번(`\\dfrac`).
- 숨겨 둔 장면의 글꼴은 저절로 안 불러와진다 — runtime 이 READY 에서 글꼴을 직접 불러온 뒤 잰다(HUSH 광고에서 겪은 문제).
- 형광 막대가 글자 높이보다 낮으면 짙은 글자의 윗부분이 어두운 바탕에 묻힌다 — 막대는 글자 전체를 덮는다.
- 한국어 줄바꿈은 `word-break: keep-all`(낱말 중간에서 끊지 않음).
