# peace-class — 수업 모션 그래픽

> **선생님이 원고를 쓰면, 영상은 점 하나가 끌고 간다.** 화면의 사실 · 값은 원고에서만 나오고, 움직임 · 소리 · 틀은 스킬이 맡는다.

Shiny Peace Studio 의 영상 엔진(videointro · videointro2: HTML 장면 → Playwright 로 프레임 → ffmpeg, 코드 작곡 — 악기 설계를 웹 오디오로 옮김)과
영상 스튜디오의 공정 원칙(단계마다 확인 · 싼 시안 먼저 · 추측하지 않기)을 수업 영상에 맞춘 스킬이다.

## 0. 시작 카드 — 원고보다 먼저, 처음에 한 번
처음 쓰는 선생님은 무엇이 필요한지 모른다. **원고를 받기 전에** 아래 1 → 2 → 3 을 한다(이미 답한 것은 건너뛴다).

### 1) 무엇이 필요한지 먼저 알린다
먼저 `python3 $SK/scripts/peace.py doctor` (`SK` = 이 스킬 폴더)를 조용히 돌려 이 환경에서 mp4 가 되는지 본다. 그 결과를 넣어 이 표를 짧게 보여 준다.

| 만들 것 | 필요한 것 | 요금제 |
|---|---|---|
| **스튜디오 파일 · 수업용 파일** (기본) | 컴퓨터 + 크롬 · 엣지 · 웨일. **설치 없음** | Claude 무료 요금제도 된다(설정에서 *코드 실행 및 파일 만들기* 를 켜고 스킬을 올리면) |
| **mp4 — Claude 가 구워 줌** | Node.js · Playwright(크로미움) · ffmpeg 가 있는 환경. `doctor` 결과가 ✅ 면 지금 바로 된다 | Claude 앱 채팅은 환경에 따라 안 될 수 있다. 선생님 컴퓨터에서 작업하는 **Claude Code · Cowork 는 유료(Pro 이상)** 이고, 위 셋을 한 번 깔아야 한다(`doctor` 가 운영체제별 명령을 알려 준다) |
| **내 목소리로 읽어 mp4 까지 — Claude 에게 맡김** | 원고(또는 교과서 사진) + **10초 목소리 샘플 하나**(PC 녹음기 · 스튜디오 🗣 샘플 녹음 · 휴대폰 음성 메모 무엇이든). 대사는 선생님이 읽지 않는다 — 전부 Claude 가 그 목소리로 읽힌다. PC · 휴대폰 모두 된다 | 설치 없음(이 작업 공간에 Claude 가 깐다 · 대화마다 처음 몇 분) · `doctor` 가 mp4 ✅ 일 때 |
| **mp4 — 직접** | 윈도우: 수업용 파일 열고 F → **Win + Alt + R** (소리 포함). 맥은 소리가 안 담겨 Claude 에게 부탁 | 무료 |

요금제 · 메뉴 이름은 바뀔 수 있다고 덧붙인다. 설치를 우기지 않는다. mp4 가 꼭 필요하지 않으면 수업용 파일을 권한다.

### 2) 체크해서 고르게 한다 — 두 번, 이 순서로
**선택지 도구(AskUserQuestion 처럼 체크로 고르는 도구)가 있으면 그것으로 묻는다**(한 번에 질문 넷 · 선택지 넷까지). 없으면 번호 목록으로 묻고 번호로 답하게 한다. **요청에 이미 들어 있는 것은 묻지 않는다** — "중1 과학 광합성, 16:9" 라고 했으면 첫 묶음은 사진만 묻거나 통째로 건너뛴다.

**첫 묶음 — 무엇을 · 어디에** (교과와 화면을 알아야 스타일을 추천하고 견본을 그 비율로 보여 줄 수 있다)

| 질문 | 선택지 |
|---|---|
| 교과 | 국어 · 수학 · 과학 · 사회/역사 (영어 · 정보 · 그 밖은 '기타'에 적게) |
| 학년 | 초등 저학년 · 초등 고학년 · 중학교 · 고등학교 |
| 화면 | 16:9 수업용(프로젝터) · 9:16 쇼츠(학생 복습 · 학급 채널) |
| 사진이 있나요? (여러 개) | 화면에 보여 줄 사진(실험 · 현장 · 자료) · 교과서 · 학습지 사진으로 원고를 대신 · 없음 |

**둘째 묶음 — 어떻게 보이고 들리게**
먼저 견본을 보여 준다: 16:9 면 `references/스타일견본.jpg`, 9:16 이면 `references/스타일견본_9x16.jpg`(같은 세 장면을 11가지 스타일로). 출력 폴더에 복사해 건네거나 화면에 띄운다.
교과 · 학년에 맞는 스타일 하나를 **(추천)** 을 붙여 그 묶음의 맨 앞에 둔다.

| 교과 · 학년 | 추천 |
|---|---|
| 국어 고전 · 역사 · 한문 | 먹 |
| 수학 · 과학 그래프 | 모눈 (어두운 교실이면 형광) |
| 사회 · 국어 비문학 | 신문 |
| 영어 · 정리 노트 | 공책 |
| 정보 · 퀴즈 | 픽셀 |
| 초등 저학년 · 동화 · 도덕 | 종이 공작 |
| 초등 · 동기 유발 · 쇼츠 | 팝 |
| 단원 도입 훅 | 예고편 |

| 질문 | 선택지 | 여러 개 |
|---|---|---|
| 어두운 바탕 | 1 형광 (형광 막대 · 박자 쾅) · 3 칠판 (분필 결 · 빗금 칠 · 지우개) · 7 청사진 (외곽선 제목 · 점선 · 십자) · 11 예고편 (검은 띠 · 빛 번짐 · 낮게 쾅) | ✔ |
| 밝은 바탕 (밝은 교실 프로젝터에 잘 보임) | 2 신문 (명조 · 빨간 밑줄 · 도장 쾅) · 4 공책 (둥근 제목 · 노랑 마커 · 포스트잇) · 5 팝 (굵은 테두리 · 통통 · 박자 쾅) · 6 모눈 (상자 강조 · 그래프) | ✔ |
| 특별한 결 | 8 먹 (한지 · 붓글씨 · 붉은 낙관) · 9 종이 공작 (크라프트지 · 색종이 · 초당 12장) · 10 픽셀 (도트 글꼴 · 8비트 소리 · 픽셀 그림) | ✔ |
| 목소리 | **내 목소리 샘플을 주면 Claude 가 대사를 읽어 넣기**(추천 · 10초 샘플 하나면 끝 · 대사는 선생님이 안 읽어도 됨 · PC 든 휴대폰이든) · 내가 장면마다 직접 녹음(스튜디오 🎙) · 녹음 파일이 있어요 · 목소리 없이 배경음만 | |

**mp4 는 따로 묻지 않는다.** 기본은 수업용 파일. `doctor` 가 ✅ 일 때만 끝에 "mp4 도 만들까요?" 를 덧붙인다.
장면 짜기에서 쓸 수 있는 것도 알려 준다: 국어 낱말은 **한글 조립** · 통계는 막대그래프 **대시보드**(커서 · 합계) · **장면마다 다른 스타일** · **박자마다 쾅** · **끝없는 줌**.

### 3) 답에 따라
- **스타일**: 체크한 것 중 첫째를 `style` 로 둔다. 장면마다 다르게 원하면 장면에 `style` 을 따로 둔다(예: 도입 cinema · 개념 board). 여러 개면 "스튜디오 위쪽에서 나란히 비교해 바꿀 수 있어요". 아무것도 안 고르면 기본(형광)으로 두고 스튜디오에서 고르게 한다.
- **직접 녹음**: 장면 표와 함께 **장면마다 녹음 대본**(한두 문장)을 준다. 녹음 방법을 세 줄로 알린다: 🎙 녹음 → 처음 한 번 *마이크 허용* → 읽고 ■ 멈추기 → ▶ 듣기(다시 녹음하면 덮어씀). 조용한 곳 · 이어폰 마이크.
- **녹음 파일**: 대화창에 올려 달라고 하고 `voice/01.m4a …` 로 두고 장면에 `"voice"`. 또는 스튜디오의 *파일* 버튼으로 넣어도 된다고 알린다.
- **내 목소리 샘플로 (Claude 가 만들기 · 기본)**: 이렇게 말한다 — "10초쯤 녹음해 올려 주세요. PC 면 스튜디오의 🗣 샘플 녹음이나 녹음기 앱, 휴대폰이면 음성 메모 앱으로요. 조용한 곳에서 문장 하나를 또박또박 읽으면 돼요. **마지막 '…요' '…다' 까지 말하고 1초 쉰 뒤 멈춰 주세요**(끝 글자가 씹히면 만든 목소리도 끝이 잘려요). 무슨 말을 했는지는 안 적어도 돼요 — 제가 받아 적어요. 대사는 제가 전부 그 목소리로 읽혀요." 받으면:
  1. 장면마다 `say`(한두 문장 · 화면 글을 그대로 읽지 말고 말하듯)를 채워 장면 표와 함께 확인받는다.
  2. `python3 $SK/scripts/peace.py voice-setup` — 이 작업 공간에 Qwen3-TTS(0.6B · CPU)를 깐다(대화마다 처음 한 번 · 몇 분 · PyTorch 와 허깅페이스에 접속돼야 함). 실패하면 아래 '직접' 방법으로 안내한다.
  3. `python3 $SK/scripts/peace.py voice <작업 폴더> --sample <샘플>` — 샘플에서 한 말을 받아 적어 화면에 보여 주고(선생님이 적어 줬으면 `--sample-text`), 장면마다 `voice/NN.wav` 를 만들어 단다(1분 영상에 대사 5~6분 · 샘플은 이 작업 공간 밖으로 나가지 않는다).
  3-1. `python3 $SK/scripts/peace.py sync <작업 폴더>` — **목소리와 이름표 맞추기**. 녹음을 받아 적어(faster-whisper · 이 작업 공간에서) 사진 장면 `pins` · 모아 보기 `cells` 의 낱말(`kw`, 없으면 이름표 첫 낱말)을 말하는 순간에 그 이름표가 뜨게 `at` 을 적는다. 이름표 낱말이 대사에 없으면 `kw` 로 대사 속 낱말을 적어 준다. 목소리가 있으면 늘 한다 — 귀가 먼저 듣고 눈이 찾는다.
  4. studio / share / video. 말 길이만큼 장면이 늘고, 말하는 동안 배경음이 작아진다. 목소리가 있는 장면은 대사가 **자막**으로 한 토막씩 나온다(`sync` 가 말하는 때를 적는다 · 끄려면 `"subs": "off"`).
  5. **mp4 와 함께 스튜디오 파일도 꼭 보낸다** — 선생님이 4 · 흐름 보기에서 장면 순서대로 그림 · 대사 · 자막을 한눈에 보고 바로 고친다. 대사를 고친 장면은 "목소리는 예전 그대로" 표시가 뜬다 → 시나리오 json 을 받으면 그 장면만 `voice --only N` → `sync` → `video`.
  **선생님 목소리는 그 선생님 것만**: 샘플 · 만든 목소리 파일은 작업 폴더에만 두고 저장소 · 예시 · 다른 사람에게 가는 파일에 넣지 않는다. 선생님이 물으면 "다른 선생님은 쓸 수 없어요"라고 분명히 말한다.
  끝 글자 씹힘: AI 는 맨 끝 글자를 끊어 버리기 쉽다("나와욕"). 그래서 `voice` 는 대사 뒤에 버리는 꼬리 말(" 네.")을 붙여 만들고, 꼬리 말 앞의 쉼에서 잘라 끝 글자가 저절로 잦아들게 한 뒤 짧은 무음을 덧댄다. 샘플 끝이 말하는 도중에 끊겼으면 경고가 나온다 — 다시 녹음을 부탁한다. 만든 뒤 장면마다 끝을 들어 보고(`ffmpeg -sseof -1`), 잘렸으면 `--only N` 으로 그 장면만 다시 만든다.
  알릴 것: **본인 목소리만**(다른 사람 목소리는 쓰지 않는다) · 학생에게 "AI 로 만든 선생님 목소리"라고 알리기를 권한다 · CPU 의 0.6B 라 선생님 컴퓨터의 1.7B 보다 조금 덜 닮을 수 있다.
- **내 목소리 샘플로 (선생님이 직접)**: 스튜디오 위쪽 **🗣 내 목소리 AI** — 샘플 녹음 → 대본 복사 → Qwen3-TTS 데모(허깅페이스 · *Voice Clone (Base)*)에서 만들기 → 받은 파일 한꺼번에 넣기. 샘플 · 대본이 외부 사이트로 간다는 것을 말한다. 데모를 Claude 가 대신 부르려면 `voice --remote`(HF_TOKEN 필요 · 로그인 안 한 무료 GPU 시간은 금방 바닥난다).
- **모아 보기**: `gallery` 장면 — 같은 그림을 스타일마다 한 칸씩 격자로(진짜 사진 `src` 가 있으면 첫 칸). 같은 그림을 여러 장면에 쓸 때는 **장면마다 설명(제목 · 글 · 짚는 곳)을 다르게** 쓴다 — 같은 말 반복은 지루하다.
- **사진이 없으면 그림으로**: 잎처럼 그림 자료가 있는 것은 `photo` 장면에 `"draw": "leaf"` — 장면 스타일에 맞춰 그려진다(칠판 분필 · 먹 · 도트 · 종이 공작 …). 사진과 구도가 같아 같은 `pins` 로 '진짜 잎 → 그린 잎' 비교 장면을 만들 수 있다.
- **보여 줄 사진**: 올려 달라고 한다 → `photo/01.jpg` → `photo` 장면. 짚을 곳은 선생님이 스튜디오에서 사진을 눌러 정한다. 학생 얼굴은 동의, 교과서 · 인터넷 그림은 저작권을 먼저 묻는다.
- **교과서 · 학습지 사진**: 읽은 글을 원문 사실로 쓰고, 읽은 내용을 장면 표에 적어 확인받는다. 흐린 글자는 추측하지 않고 묻는다.
- **mp4**: `doctor` 가 ✅ 면 스튜디오 다음에 굽는다. ❌ 면 `doctor` 가 알려 준 설치 명령(유료 Claude Code · Cowork 로 선생님 컴퓨터에서 할 때) 또는 윈도우 화면 녹화를 안내한다.

## 1. 원고 받기 → 장면 표 ⏸
선생님에게 받을 것: **주제 · 대상(학년 · 어디에 쓰나) · 전할 것 한 문장 · 원문 사실(정의 · 값 · 연도 · 예문) · 마무리 한 마디**.
빠진 것만 한 번에 묻는다(선택지 도구 · 넷까지). 시작 카드에서 이미 받은 답(스타일 · 목소리 · 사진 · 결과물)은 다시 묻지 않는다.

- **사진으로 받을 때**: 교과서 · 학습지 · 판서 사진을 주면 글을 읽어 원문 사실로 쓰고, 읽은 내용을 장면 표에 적어 확인받는다(흐린 글자는 추측하지 않고 묻는다). 실험 · 현장 사진처럼 **화면에 보여 줄 사진**은 `photo` 장면에 넣고(`작업 폴더/photo/01.jpg` → `"src": "photo/01.jpg"`), 짚을 곳은 선생님이 스튜디오에서 사진을 눌러 정한다. 교과서 그림 · 인터넷 사진은 저작권, 학생 얼굴은 동의를 먼저 묻는다.
- **원문 사실에 없는 사실 · 숫자 · 연도는 넣지 않는다.** 교과 내용을 대신 지어 쓰지 않는다 — 모르면 묻는다.
- 함수 식 · 그래프 값처럼 원고에서 계산되는 것(기울기 삼각형의 +1 · +2)은 된다. 계산 결과를 장면 표에 적어 확인받는다.
- 비율: 수업(프로젝터) = 16:9 · 학생 복습 · 학급 채널 쇼츠 = 9:16. 분위기: 대부분 calm, 저학년 · 놀이 = bright, 무거운 주제 = serious.

**연출 의도 먼저 — 학생이 무엇에 집중하길 바라나.** 사람은 귀로 들은 것을 눈으로 찾는다. 화려함만 앞서면 "재밌었다"로 끝난다.
- 수업용은 **스타일 하나**(많아야 둘). 장면마다 스타일을 바꾸는 것은 소개 · 이벤트 영상용이다.
- 장면 하나 = 전할 것 하나. 화면 글은 짧게(말이 설명한다), 짚는 곳은 말과 같은 순간에(`sync`).
- 같은 그림을 여러 번 쓰면 장면마다 설명을 다르게. 마무리 모아 보기는 스타일 자랑이 아니라 **배운 것 정리**(`cells` 에 칸마다 배운 내용 · 짚는 자리).

장면 표를 짜서 보인다(장면마다: 틀 · 화면에 나올 글 · 점이 하는 일 · 대략 초). 공식은 `장면틀.md` "짜는 법". **"좋아요" 전에는 다음으로 가지 않는다.**

## 2. 스튜디오 파일을 만들어 드린다 ⏸ — 스타일 · 시나리오는 선생님이 눈으로 보고 고른다
```bash
SK=<이 스킬 폴더>
python3 $SK/scripts/peace.py new    <작업 폴더> --from science-photosynthesis   # 가장 가까운 예시로 시작
#   → <작업 폴더>/lesson.json 을 장면 표대로 고친다 (형식 = references/장면틀.md)
python3 $SK/scripts/peace.py studio <작업 폴더>                                # → <제목>_스튜디오.html (파일 하나 · 글꼴을 통째로 담아 약 7MB)
```
**스튜디오 파일이 이 스킬의 중심이다.** 선생님이 내려받아 브라우저로 열면(인터넷 · 설치 없음):
스튜디오는 **4단계로 한 번에 한 가지만** 보인다(위 단계 막대 · 오른쪽 위 '다음 →'): ① 스타일 · 효과 → ② 글 · 목소리 → ③ 흐름 보기 → ④ 저장. 효과(장면 넘김 12가지 · 박자마다 쾅)도 설명이 아니라 움직이는 모습으로 고른다 — 넘김은 넘어가는 순간만 느리게, 쾅은 3배로 크게 보여 준다.
0. **처음 화면 — 움직이는 스타일 11가지** — 지금 수업의 첫 장면들이 스타일마다 실제로 움직이며 나온다(설명을 읽고 고르지 않는다 · 사람들은 이름과 설명만으로는 모른다). 🔊 크게 보기로 소리와 함께 한 바퀴. 누르면 그 스타일로 시작.
1. **스타일 고르기** — 지금 장면이 스타일 11가지(형광 · 신문 · 칠판 · 공책 · 팝 · 모눈 · 청사진 · 먹 · 종이 공작 · 픽셀 · 예고편)로 나란히 보인다. 눌러서 고른다.
2. **시나리오 고치기** — 장면마다 화면에 나올 글이 칸으로 있다. 고치면 바로 미리보기에 나온다. 장면 더하기 · 지우기 · 순서 바꾸기 · 복제.
3. **목소리** — 장면마다 🎙 녹음(마이크) 또는 파일. 말 길이만큼 장면이 늘고, 말하는 동안 배경음이 낮아진다.
4. **미리보기 · 점검** — 소리와 함께 재생, 넘침 · 겹침을 저절로 점검해 알려 준다.
4-1. **흐름 보기** — 장면마다 그림 한 장 · 시간 · 대사 칸 · 자막 토막이 순서대로 놓인다. 그림을 누르면 미리보기가 그 장면으로 가고, 대사 칸을 고치면 자막이 바로 바뀐다.
4-2. **영상 파일로 저장(4단계)** — 브라우저가 한 번 재생하며 영상 칸만 녹화해 mp4(H.264 · 소리 포함)로 저장한다(탭 화면 공유 + 영역 자르기 · Claude 없이 · 아티팩트 안에서는 안 됨). 선생님이 'mp4 는 어떻게?' 하면 먼저 이것을 알린다.
5. **수업용 파일 저장** — 재생기 파일 하나(`<제목>_수업용.html`)로 저장. 이것을 수업에 쓰고 다른 선생님께 보낸다.
6. **시나리오 저장** — `.json` 으로 저장해 두면 나중에 "시나리오 열기"로 이어서 고치거나, Claude 에게 보내 손보게 할 수 있다.

**Claude 화면 안에서 바로 열리게(아티팩트)**: `Artifact` 도구가 있으면 스튜디오를 아티팩트로도 올린다 — `capabilities: {"downloads": true}`(수업용 파일 · 시나리오 저장이 된다). 선생님은 내려받지 않고 Claude 안에서 바로 스타일을 보고 고친다. 아티팩트 안에서는 마이크를 쓸 수 없어 🎙 이 '녹음 파일 넣기'로 바뀐다(휴대폰 음성 메모 · PC 녹음기 파일). **선생님 목소리가 든 판은 선생님이 원할 때만 올린다** — 기본은 목소리를 뺀 판(`voice` · `voiceData` · `cues` 를 지운 lesson 으로 `studio`), 목소리 든 스튜디오는 파일로 보낸다. 아티팩트는 처음에 선생님만 보이고, 공유는 선생님이 정한다.
선생님에게 보낼 것: 스튜디오 파일(`SendUserFile` · display: attach) + 한 줄 안내("내려받아 크롬 · 엣지 · 웨일로 열어 주세요. 1 스타일 → 2 글 고치기 → 수업용 파일 저장") + **화면 글자를 교과서와 대조해 달라는 부탁**.
선생님이 시나리오 json 을 다시 보내면 그것을 lesson.json 으로 두고 이어서 작업한다(스타일 · 녹음도 그 안에 있다).

Claude 가 직접 확인할 때(Node + Playwright 가 있는 환경): `peace.py build` → `peace.py check` 로 정지 화면 시트 · 화면 글자 · 점검을 먼저 본다 — 글 겹침 · 잘림 · 빈 화면을 고친 뒤 스튜디오를 보낸다.

```bash
python3 $SK/scripts/peace.py share <작업 폴더>          # 수업용 파일 하나를 바로 (스튜디오를 거치지 않을 때 · 글꼴을 쓴 글자만 담아 약 1MB · fontTools 가 없으면 통째로 7MB)

```
- 수업용 파일 조작: 클릭 · 스페이스 = 재생/멈춤 · → ← = 다음/앞 장면 · F = 전체 화면 · R = 처음부터. 멈춰 있으면 제목 화면이 표지.
- 처음 쓰는 선생님께는 "설치할 것이 없다 — 내려받아 크롬 · 엣지 · 웨일로 열면 된다(카카오톡 · 메일 미리보기 · GitHub 화면 안에서는 안 열린다)"를 먼저 알린다. 스튜디오의 **처음이세요? 쓰는 법** 버튼에 같은 안내가 있다.
- mp4 가 안 되는 환경이면 "수업용 파일을 쓰시거나 화면 녹화로 mp4 를 만들 수 있어요"라고 알린다. 설치를 우기지 않는다.

## 4. 목소리
선생님 목소리가 가장 좋다. 길은 셋 — ① 샘플 10초를 받아 Claude 가 이 작업 공간에서 대사를 읽어 넣기(`voice-setup` → `voice` · 시작 카드 3) 참고) ② 선생님이 스튜디오에서 장면마다 🎙 녹음 ③ 녹음 파일을 받아 `voice/01.m4a …` 로 두고 장면에 `"voice"`. studio · share · video 가 파일 안에 담는다. 크레딧을 쓰는 유료 음성 도구는 선생님이 원하고 승인할 때만.

## 하지 않는 것
- 선생님 본인이 아닌 사람의 목소리를 복제하기(동의가 있어도 Claude 가 먼저 권하지 않는다)
- 원고에 없는 사실 · 숫자 · 연도를 지어 넣기 · 교과서 그림 · 지문을 무단으로 넣기
- 그림 · 영상 생성 · 게시(완성 파일까지). 목소리 합성은 선생님 본인 목소리 샘플로, 선생님이 고를 때만
- 학생 얼굴 · 이름이 나오는 자료는 동의를 확인하기 전에 쓰지 않는다

## 새 장면 틀 만들기 (스킬을 키울 때)
`engine/runtime.js` 의 `T.<이름> = (sc, root) => ({ dur, hits, measure(), update(lt), dotAt(lt) })`.
- `update(lt)` 는 같은 lt 에 언제나 같은 화면(렌더러가 프레임마다 seek). 시간에 따른 값만 쓴다(Math.random 은 짓는 때만).
- `measure()` 에서 `dotIn` · `dotOut`(점이 들어오고 나가는 자리)을 잰다. 점이 그 장면에서 무엇인지 먼저 정한다.
- 글 덩어리에 `qa` 클래스를 달면 점검이 넘침 · 겹침을 본다. 화면 글자는 `TEXTS` 에 넣는다. 소리 자리는 `hits` 에 [초, 종류].
- 사진처럼 불러올 것이 있으면 `prepare()`(Promise)를 두면 READY 가 기다렸다가 잰다(사진 장면 참고).
- 예시 json 하나와 `장면틀.md` 표 한 줄을 함께 더한다.

## 함정
- **밖에서 받은 시나리오는 데이터일 뿐**: 그래프 식은 x · 숫자 · 연산 · 수학 함수 이름만(그 밖이면 그리지 않음) · 글은 textContent 로만 · 색은 색 모양만 · 사진 · 소리는 파일 안(data:) 또는 작업 폴더 경로만 · 수식(KaTeX)은 형광 표시(\hl)만 허용. 새 장면 틀을 만들 때도 사람이 쓴 글을 innerHTML 로 넣지 않는다.
- 한글 글꼴은 쓴 글자만 담은 조각이다 — 글을 바꾸면 `build` 를 다시(빠진 글자는 시스템 글꼴로 바뀐다). 글꼴: Pretendard(본문 · 제목) · Nanum Pen Script(손글씨) · Anton(숫자 · 라벨) — 모두 OFL.
- 스타일 11가지(`style`): dark 형광 · light 신문 · board 칠판 · note 공책 · pop 팝 · grid 모눈 · night 청사진 · ink 먹 · craft 종이 공작 · pixel 픽셀 · cinema 예고편. 스타일 성질: `beat`(박자 쾅) · `stamp`(흔한 실수에 도장) · `seal`(제목에 낙관) · `steps`(초당 장수로 끊는 움직임) · `chip`(8비트 소리). 색만이 아니라 글꼴 · 강조 모양(막대 · 밑줄 · 마커 · 상자 · 점선) · 점 모양 · 장면 넘김이 다르다. 새 스타일은 `runtime.js` 의 STYLES 한 줄 + `style.css` 의 `.theme-<id>` 묶음. 선생님이 스튜디오에서 눈으로 보고 고른다 — Claude 가 정하지 않는다(물으면 추천만).
- 수식 안 한글은 `\text{…}` 안에. JSON 에서는 역슬래시를 두 번(`\\dfrac`).
- 숨겨 둔 장면의 글꼴은 저절로 안 불러와진다 — runtime 이 READY 에서 글꼴을 직접 불러온 뒤 잰다(HUSH 광고에서 겪은 문제).
- 형광 막대가 글자 높이보다 낮으면 짙은 글자의 윗부분이 어두운 바탕에 묻힌다 — 막대는 글자 전체를 덮는다.
- 한국어 줄바꿈은 `word-break: keep-all`(낱말 중간에서 끊지 않음).
