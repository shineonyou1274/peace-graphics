# 장면 틀 — lesson.json 쓰는 법

영상 한 편 = `lesson.json` 한 장. 장면은 `scenes` 에 차례로 적는다. **화면에 나오는 글자 · 값은 모두 이 파일에서만 나온다.**

## 머리
| 칸 | 뜻 | 예 |
|---|---|---|
| `title` | 영상 이름 (파일 이름이 된다) | "일차함수의 기울기" |
| `subject` | 과목 — 강조색이 정해진다 (수학 형광 연두 · 과학 하늘 · 국어 분홍 · 영어 주황 · 사회 보라) | "수학" |
| `unit` | 학년 · 단원 (왼쪽 위 라벨) | "중2 · 일차함수" |
| `ratio` | "16:9" (수업 · 프로젝터) / "9:16" (쇼츠) | "16:9" |
| `mood` | 소리 분위기 — calm(기본 · 잔잔한 로파이) / bright(밝고 통통) / serious(무거운 주제 · 단조) | "calm" |
| `style` | 스타일 — dark 형광(기본) · light 신문 · board 칠판 · note 공책 · pop 팝 · grid 모눈 · night 청사진 · ink 먹 · craft 종이 공작 · pixel 픽셀 · cinema 예고편 (스튜디오에서 눈으로 고른다) | "board" |
| `accent` | 강조색을 직접 (선택) | "#d7ff00" |
| `brand` | 왼쪽 아래 라벨 (기본 PEACE CLASS) | "3학년 2반" |
| `seed` | 소리 바꾸기 — 숫자를 바꾸면 효과음 결이 조금 달라진다 | 7 |

## 글자 안에 쓰는 표시
- `$...$` — 수식 (KaTeX · LaTeX 문법). 예: `$\dfrac{y\text{의 증가량}}{x\text{의 증가량}}$` · 한글은 `\text{…}` 안에
- `[[...]]` — 형광으로 칠할 곳 (일반 글)
- `\hl{...}` — 형광으로 칠할 곳 (수식 안 · steps 의 lines)

## 수업 전체 설정 (머리에 더 적을 수 있는 것)
- `beat`: "on" · "off" — 박자마다 쾅(배경음 박자에 맞춰 장면이 살짝 튐). 적지 않으면 스타일대로(형광 · 팝 · 픽셀 · 예고편은 켜짐)
- `trans`: "zoom" — 끝없는 줌 넘김(점이 있는 곳으로 빨려 들어가고 다음 장면이 그 점에서 열림). 적지 않으면 스타일대로

## 장면 틀 12가지
모든 장면에 `style`(이 장면만 다른 스타일 · 비우면 수업 스타일)과 `say`(읽을 대본 · 화면에는 안 나옴 · 녹음 · AI 목소리용)를 적어 둘 수 있다. `dur`(초)를 적으면 그 길이로, 안 적으면 내용에 맞춰 정해진다. `voice`("voice/01.wav")를 적으면 그 녹음을 깔고 말 길이만큼 머문다(스튜디오에서 녹음하면 `voiceData` · `voiceDur` 로 파일 안에 담긴다).

| type | 쓰는 곳 | 칸 |
|---|---|---|
| `title` | 첫 화면 · 단원 제목 | `title` · `sub`(손글씨 한 줄) · `kicker`(위 작은 글 · 기본 = 과목 · 단원) · `size` |
| `concept` | 용어 · 정의 | `term` · `text` · `keys`(text 안에서 형광펜으로 칠할 말 — text 에 그대로 있어야 한다) · `label`(기본 "개념") |
| `steps` | 수식 전개 · 풀이 · 문장 바꾸기 | `lines`(한 줄씩 · 기본 수식) · `tex`(false 면 일반 글) · `title` · `note`(손글씨) · `gap`(줄 간격 초) · `keep`(true 면 지난 줄을 흐리지 않음) |
| `graph` | 함수 그래프 · 좌표평면 | `fns`: [{`f`: "2*x+1", `label`: "y = 2x + 1"}] (f 는 JavaScript 식 · `x**2` · `sin(x)` · `sqrt(x)`) · `x`: [-5,5] · `y`: [-5,5] · `points`: [[1,3], [2,5,"이름"]] · `tri`: {fn, at, dx} 기울기 삼각형 · `note` · `step`(눈금 간격) |
| `bars` | 막대그래프 · 통계 | `title` · `items`: [["걷기",14], …] · `unit` · `source`(출처 · 기준 연도) · `cursor`(true 면 커서가 가장 큰 막대를 눌러 값을 띄움 · 대시보드) · `total`(true 면 합계 카드가 숫자를 셈) |
| `timeline` | 연표 · 순서 | `events`: [["1392","조선 건국"], …] · `title` · `scale`(true 면 연도 간격에 맞춰 띄움) · `per`(사건 하나 초) |
| `compare` | 둘 비교 | `left`/`right`: {`title`, `points`: […]} · `vs`(가운데 글 · 기본 vs) |
| `fix` | 흔한 실수 → 바로잡기 | `wrong` · `right` · `why`(손글씨) · `label`/`label2` |
| `process` | 과정 · 단계 · 실험 순서 | `steps`: ["…", …] · `title` · `per` |
| `photo` | 사진 · 실험 장면 · 자료 그림 (짚으며 설명) | `src`(사진 · 작업 폴더 안 경로 또는 data URL) 또는 `draw`(사진 대신 그림 · 지금은 `"leaf"` 잎 — 장면 스타일에 맞춰 분필 · 먹 · 도트 등으로 그려지고 선이 그려지며 나타남 · 판 650×540, 잎자루 (17,74) · 잎맥 (69,45) · 잎몸 (51,27)) · `pins`: [{`x`, `y`, `label`, `at`?, `kw`?}] (사진 위 % 자리 · 차례로 짚음 · `at` = 짚는 때(초) — `sync` 가 목소리에서 `kw`(없으면 이름표 첫 낱말)를 찾아 적는다) · `title`(위 작은 글) · `caption`(설명 · `[[형광]]`) |
| `gallery` | 모아 보기 — 같은 그림을 칸마다 격자로 (마지막 정리 화면) | **수업 정리**: `cells`: [{`label`(배운 것 한 줄), `x`, `y`(짚는 자리 %), `kw`?, `at`?}] — 장면 스타일 하나로 · **스타일 소개**: `styles`(스타일 id 목록 · 기본 11가지 전부) · `draw`(기본 `"leaf"`) · `src`(진짜 사진 · 있으면 첫 칸 '진짜') · `title`(위 작은 글) · `note`(아래 손글씨 한 줄) |
| `hangul` | 국어 낱말 · 음운 · 자모 | `words`: [["불","타오르는 불"], ["풀","들판의 풀"], …] (차례로 바뀜 · 첫 낱말은 자모가 날아와 조립, 다음부터는 바뀐 자모만 갈아 끼움 · 같은 글자 수가 좋다) · `title` · `note` |
| `end` | 마무리 한 마디 | `text`(손글씨) · `sub`(다음 시간 등) |

## 짜는 법 (수업 영상 공식)
1. **title** — 오늘 배울 것 한 단어 + 손글씨 한 줄
2. **concept** 또는 **fix** — 정의, 또는 "흔한 실수"로 호기심 열기
3. 설명 장면 2~4개 — steps · graph · bars · timeline · compare · process 중 내용에 맞는 것. **같은 틀을 연달아 쓰지 않는다**
4. **end** — 마무리 한 마디(전할 것 한 문장)

- 영상 하나 = 전할 것 하나. 40초~1분 30초가 알맞다.
- 장면 하나 = 개념 하나. 글이 길면 장면을 나눈다(정의 한 문장 · 줄 3~5개 · 사건 3~6개 · 막대 3~7개).

## 점 하나
모든 장면을 형광 점 하나가 끌고 간다 — 제목을 밝히고, 형광펜이 되고, 곡선을 그리는 펜 끝이 되고, 막대 꼭대기를 건너뛰고, 연표의 시간이 되고, 마지막엔 마침표가 된다. 장면 사이에서는 포물선(아크)으로 날아가며 빠를수록 늘어난다(스쿼시 앤 스트레치). 새 장면 틀을 만들 때도 **점이 그 장면에서 무엇인지**를 먼저 정한다.
